# Бэктест модели КХЛ

`bt.py` — точная копия расчёта таблицы КХЛ (Elo из `computeAndWriteElo_` + формула «Шансы хозяев» на листе «прогнозы»)
с параметрами, чтобы проверять изменения модели на сыгранных матчах до того, как менять таблицу.

`data.json` — выгрузка из таблицы: результаты 2025-26 (748) и 2026-27, броски в створ по протоколам (лист «Составы_матчей»),
закрывающие линии 1X2 (лист «Архив_линий») — для сравнения с рынком, стартовые рейтинги.

```python
from bt import *
cur = sorted(D['cur'], key=lambda g: g['d'])
print(score(run(cur, D['start'], {})))                                   # модель как была до 03.10.2026
print(score(run(cur, D['start'], dict(fon=0, S=100, shrink=0.8, proc=0.5))))   # модель v2
```

Итоги 03.10.2026 (Brier, меньше — лучше; линия букмекера на тех же 70 матчах — 0.2212):

| | 2026-27 (115) | 1-я половина | 2-я половина | 2025-26 (548) | 70 матчей с линией |
|---|---|---|---|---|---|
| было: форма, разброс 4…93, чувствительность 90 | 0.2290 | 0.2112 | 0.2464 | 0.2279 | 0.2267 |
| v2: без формы, старт ×0.8, броски 0.5, чувствительность 100 | 0.2247 | 0.2080 | 0.2411 | 0.2265 | 0.2178 |

Что не помогло: серии и форма поверх Elo (удваивают уже учтённые результаты), K быстрее 20,
отдельная поправка за «везение» (PDO) поверх бросков — в пределах шума.
