# Apps Script таблицы «КАПЕР ДЖАРВИС КХЛ»

`project/` — копия кода, привязанного к таблице (Расширения → Apps Script),
скачанная через [clasp](https://github.com/google/clasp).
Вся автоматика — парсер, прогнозы, посты в Telegram, LIVE, разведчик, досье —
работает там, по расписанию из листа «Автоматика».

Секретов в коде нет: ключи (Telegram, Gemini, Tavily и др.) хранятся в свойствах
скрипта (Настройки проекта → Свойства скрипта) и в репозиторий не попадают.

Скачать свежую версию из таблицы:

    cd apps-script/project && clasp pull

Загрузить изменения обратно в таблицу (заменяет ВСЕ файлы проекта —
перед этим обязательно `clasp pull` и сверка):

    cd apps-script/project && clasp push

Когда clasp недоступен, изменения вставляются в редактор вручную: в `patches/`
лежат готовые куски кода с пошаговой инструкцией в начале файла (что найти,
что выделить, чем заменить). Файлы `project/` и `nhl/` при этом уже содержат
то же изменение — после ручной вставки код в таблице совпадает с репозиторием.
