# Инфографика JARVIS | KXL — набор для генерации баннеров

Состав:
- poster.py — генератор. Основные функции:
  - render_clean(home, away, info, path) — вариант «Бока» (информация по бокам от эмблем; Oswald + Manrope + Unbounded)
  - render_cards(home, away, info, path) — вариант «Карточки» (каждая команда в стеклянной карточке; Montserrat Black + Unbounded, в стиле постов КХЛ)
  - team_info(games, points, form) — строка «очки · игры» + форма за 5 матчей
- make_today.py — пример запуска на матчи 22.09 (что подставлять: названия команд как в TEAMS, коэффициенты П1/Х/П2 в основное время, игры, очки, форма)
- emblems/ — 22 подготовленные эмблемы клубов (без фона, без обрезаний)
- fonts/ — шрифты Google Fonts (OFL, бесплатные)

Форма (строка из букв, последние 5 матчей, слева старые → справа свежие):
  W — победа в основное время (зелёный «В»)
  L — поражение в основное время (красный «П»)
  X — победа в ОТ/буллитах (половина белая + зелёная, «ОТ»)
  O — поражение в ОТ/буллитах (половина белая + красная, «ОТ»)
Форма считается из листа «результаты матчей» (колонка «ОТ/буллиты?») таблицы «КАПЕР ДЖАРВИС КХЛ».

Стиль, согласованный с автором канала:
- сверху «JARVIS | KXL» (KXL золотом), акцентный цвет — золото #FFC23D (фаворит по коэффициенту, рамка времени)
- без подписей о сериях — только форма за 5 матчей
- подпись снизу: «коэффициенты в основное время по данным аналитической таблицы»
- текст и инфографика чистые, зерно/текстура только на фоне
- коэффициенты — линия Pinnacle (guest API, лига 1484), переведённая в десятичные, основное время (period 6)

Запуск: pip install pillow numpy; python3 make_today.py
