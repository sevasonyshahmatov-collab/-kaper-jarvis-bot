# Инфографика JARVIS — НХЛ

Надстройка над набором КХЛ. Ничего в `poster.py` не менялось: НХЛ вписывается
в те же структуры, что и КХЛ, и дальше работают те же механизмы.

## Запуск

```python
import nhl, nhl_kit
nhl.register()          # один раз в начале скрипта
```

`register()` вписывает 32 клуба НХЛ в `poster.TEAMS`, `poster.SHORT` и
`poster.BANNER`, поэтому после него с командами НХЛ работает вообще любой
рендер набора — и КХЛ-шный тоже, если вдруг понадобится.

## Оформление

| | КХЛ | НХЛ |
|---|---|---|
| одиночный матч | «Карточки» | «Бока» |
| акцент | золото `#FFC23D` | лёд `#7ACAFF` |
| шапка | JARVIS \| KXL | JARVIS \| NHL |

## Семь типов баннеров

```python
nhl_kit.preview(home, away, info, path)          # предматчевая, линия П1/Х/П2
nhl_kit.pick(m, path)                            # прогноз на матч
nhl_kit.result(home, away, sh, sa, path, ...)    # счёт + вердикт
nhl_kit.slate(items, path, date_title=...)       # афиша дня
nhl_kit.picks(items, path, date_title=...)       # прогнозы дня
nhl_kit.hits(items, path, date_title=...)        # прогнозы зашли
nhl_kit.results_day(items, path, date_title=...) # итоги дня
```

Что ждёт каждая функция:

```python
info  = dict(when='ЧТ 01.10 · 03:00 МСК', odds=(П1, Х, П2),
             home=team_info(игры, очки, 'WLXWW'), away=team_info(...))

m     = dict(when=..., pred='Победа Вегаса с учётом ОТ и буллитов', coef=1.81,
             home=dict(team='Вегас', name='Вегас', **team_info(4, 6, 'WWLXW')),
             away=dict(team='Сан-Хосе', name='Сан-Хосе', **team_info(4, 2, 'LLWLL')))

slate       items = [dict(home, away, when='03:00 МСК', odds=(П1, Х, П2))]
picks       items = [dict(home, away, when='03:00', pred, coef)]
hits        items = [dict(home, away, score='4:1', mark='ОТ'|'', pred, coef, ok=True)]
results_day items = [dict(home, away, sh, sa, mark='ОТ'|'Б'|'')]
```

`mark` — как закончился матч: `'ОТ'`, `'Б'` или пусто.

## Названия команд

Можно писать как угодно — `resolve()` понимает русское и английское название,
аббревиатуру, прозвище и частые опечатки:

```
'Миннесота' = 'минессота' = 'MIN' = 'Minnesota' = 'уайлд'
'Нью-Йорк Рейнджерс' = 'рейнджеры' = 'NYR' = 'Rangers'
'Вегас' = 'Лас-Вегас' = 'VGK' = 'голден найтс'
```

Если название не опознано, будет `KeyError` со списком вариантов — молча
неправильную команду не нарисует.

## Цвета

В НХЛ половина лиги красная и половина тёмно-синяя, поэтому пары сливаются
чаще, чем в КХЛ. `nhl_kit` перед каждым рендером сам вызывает
`nhl.pair_colors(home, away)`: если основные цвета ближе порога, гости
уводятся во второй клубный цвет. Руками, как в КХЛ, ничего править не нужно.

Если всё же хочется задать цвет вручную — как обычно:

```python
poster.BANNER['Эдмонтон'] = (4, 30, 66)
```

## Очки и форма

Система очков НХЛ совпадает с нынешней КХЛ: победа 2, поражение в ОТ или по
буллитам 1, поражение в основное время 0. Значит работает та же проверка,
через которую проходит каждая строка перед рендером:

```
очки == 2 * победы + 1 * поражения_в_ОТ
```

Буквы формы те же: `W` победа в основное, `L` поражение в основное,
`X` победа в ОТ/буллитах, `O` поражение в ОТ/буллитах.

Время матчей приводим к МСК — американские игры сдвигаются на сутки.

## Эмблемы

30 клубов из 32 — настоящие логотипы, `emblems/nhl_<abbr>.png`
(Миннесота и Даллас лежат как `minnesota.png` / `dallas.png`).

**Нет логотипов: Калгари и Лос-Анджелес.** Скачать их нельзя — прокси режет
и Wikipedia, и GitHub. Пока файла нет, рисуется заглушка: круг в клубных
цветах с аббревиатурой. Это не логотип клуба, просто чтобы баннер собирался.

Поставить присланный логотип:

```python
nhl.install_logo('Калгари', '/путь/к/файлу.png')   # обрежет поля, снимет заглушку
nhl.missing_logos()                                # у кого ещё заглушка
```

Белый фон снимать не нужно — если он есть, снимается заливкой от краёв,
белое внутри логотипа не страдает.
