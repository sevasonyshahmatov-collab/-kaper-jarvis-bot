# Утверждённые шаблоны роликов (шортсы) — для всех будущих видео

только на них (или по прямой просьбе владельца). Остальные форматы из `render/reels/` не утверждены или отклонены
(список внизу) — к ним не возвращаемся.

открыть и посмотреть, как должно выглядеть).

Все ролики вертикальные 1080×1920, 30 к/с, под музыку владельца.

## Общие правила
Подробно — `team/RULES.md`, разделы «Ролики» и «Хранение роликов».
- Без процентов шанса — только прогноз и кэф. Без заголовков-рубрик на экране. Темп ~21–24 с.
- Нижняя зона под безопасной (ниже y=1480) — подвал `core.footer` только в последние 2,5 с: «Ссылка на канал — в описании» (решение владельца 18.10, см. ниже).
- Музыка играет до конца без затухания. Две версии: со звуком и `_clean` без музыки (на случай Content ID).
- В одном задании Actions — не больше 2–3 роликов.
- **Каждый готовый ролик сохраняется**: `python tools/video_archive.py <папка> <ролик.mp4>` → `videos/архив/<папка>/`,
  коммит в той же работе.

## Решения владельца 18.10 (движок `render/reels/core.py`, для всех шаблонов)
- **Плашка Telegram снизу — только в конце ролика** (последние 2,5 с): по ходу ролика она мешала читать текст.
  Раньше (14.10) она стояла весь ролик. Отключить нижнюю зону совсем — `REELS_FOOTER=0`.
- **Поле по краям**: на телефоне кадр выглядел «тютелька в тютельку», чуть больше экрана. Теперь кадр ужат до 94 %
  и стоит по центру на размытой затемнённой копии самого себя. Без поля — `REELS_INSET=1`.
