# Утверждённые форматы роликов (шортсы) — для будущих видео

Владелец выбрал эти форматы:
- **12.10**: «хорошие форматы, сохраняем»;
- **14.10**: «запоминаем для будущих видео».

Это все утверждённые форматы. Остальные форматы из `render/reels/` не утверждены или отклонены.

Все ролики вертикальные 1080×1920, под музыку владельца, с одинаковой драматургией:
1. матч и линия П1 · Х · П2 (крупные плашки под названиями команд);
2. команда 1 — последние 3 игры, очки, место;
3. команда 2 — то же;
4. **прогноз ровно на дроп трека**, в финале только команда, на которую прогноз, без «VS»;
5. плашка Telegram «@jarvibet».

## Общие правила для всех роликов
Подробнее — `team/RULES.md`, раздел про ролики.

- **Нижняя зона не пустая.** Подвал `core.footer` ниже y=1480: затемнение, крупная плашка Telegram, в последние 2,5 с — «Ссылка на канал — в описании».
- **Музыка** играет до конца ролика, без затухания.
- **Текст «TELEGRAM / @jarvibet»** центрирован по плашке. **@jarvibet** стоит внизу безопасной зоны во всех сценах.
- **Треки владельца** хранятся зашифрованными: модуль `render/reels/owner_tracks.py`, ключ — секрет `TRACKS_KEY` в GitHub. Сами треки в репозиторий не кладутся, просить их в чат не нужно.
- **В одном задании Actions** — не больше 2–3 роликов (лимит времени).
- **Каждый готовый ролик сохраняется в архив** (правило 17.10): `python tools/video_archive.py <папка> <ролик.mp4>` → `videos/архив/<папка>/`, коммит в той же работе. Ролики 12.10 и 14.10 тогда потерялись — их нужно пересобрать заново по этим файлам.
