# Блог на sports.ru

Владелец 22.10: «проработаем шаблоны для sports.ru, попробуем зарегистрироваться, писать посты, посмотрим, что получится».
У sports.ru нет API для публикации (поиск 22.10 не нашёл; в редакторе пост выходит только по кнопке «Опубликовать»), а
автопостинг через браузер с логином ненадёжен и грозит блокировкой. Поэтому — полуавтомат, как с роликами: пост собирается
сам и приходит владельцу в Telegram, владелец вставляет его в редактор блога (2–3 минуты).

## Что приходит (`post.py`, задание `.github/workflows/sportsru.yml`)
Тремя сообщениями: служебная строка (вид поста, теги, найденные нарушения правил), **заголовок**, **текст**.

| Когда (МСК) | Вид | Что внутри |
|---|---|---|
| вт, чт, сб 07:17 | `match` — разбор матча | самый уверенный прогноз КХЛ дня: линия П1·Х·П2, форма обеих команд (место, очки, разница шайб, 3 последние игры), 10 000 розыгрышей модели и самые частые счета, «цифра матча», прогноз и кэф |
| вс 07:17 | `day` — прогнозы дня | все матчи КХЛ дня с прогнозом: форма В-П за 3 игры, «цифра матча», прогноз и кэф |
| пн 09:37 | `week` — итоги недели | все прогнозы канала за неделю со счётом и знаком ✅/❌/↩️, «зашло N из M» и итог в единицах |

Заголовки — как ищут люди: «Сибирь — Трактор: прогноз на матч 23 октября 2026», «Итоги прогнозов за неделю: 20–26 октября».
Вручную: Actions → «Посты sports.ru» → Run workflow (вид, лига, день, клуб для разбора).

## Правила текстов
Те же, что у постов канала (`team/daily/compose.validate`): без «Джарвис», букмекеров, промокодов, гарантий и слова
«таблица»; «ставь» не пишем; итоги — и зашедшие, и нет. Нарушение — в служебной строке «Проверьте: …».
Ссылка в конце каждого поста — на Telegram `t.me/jarvibet`.

## Советы по блогу
- Не каждый день: 3–4 поста в неделю. Одинаковые ежедневные посты на sports.ru собирают минусы.
- Ролик по матчу можно вставить в пост ссылкой на YouTube (кнопка видео в редакторе).
- Правила sports.ru о прогнозах и ссылках на Telegram официально не нашлись — первые посты смотрим, как примут
  модераторы и читатели.
