# ТЗ: недельные ролики и антирейтинги (идея владельца 30.10)

## Задача: два новых формата Reels с удержанием до конца — «Топ недели» (пн) и «Антирейтинг сезона» (КХЛ и НХЛ отдельно)
**Зачем:** рост охвата и досмотра Instagram, доверие через честные цифры, сохранения и комментарии (вопрос в конце).
**Для кого:** подписчики Instagram / Reels; копия в Telegram-канал и Shorts.

## Формат 1. «Топ недели» (по понедельникам, неделя пн–вс)
- КХЛ и НХЛ — два отдельных ролика. Обратный отсчёт 5→1, №1 скрыт (размытая эмблема) до последних ~3 с, открывается на дроп трека.
- Темы по очереди: самые результативные команды недели → лучшие бомбардиры → лучшая серия (допущение: тема меняется каждую неделю).
- В конце — честный итог наших прогнозов «зашло X из Y» за ту же неделю. Только из `team/PICKS.md` и итогов дня
  (`team/daily/ledger.py`); ставки владельца считать по фактической (`team/INBOX.md`). Нет данных — блок не показывать.

## Формат 2. «Антирейтинг сезона»
- Первый выпуск: «Худшая команда КХЛ для тотала больше» — 5→1 по доле матчей сезона с тоталом меньше 5,5 (основное время).
  На экране: «в N из M матчей меньше 5,5 шайб» и средний тотал команды. Подача — как факт статистики, не совет ставить.
- Очередь: «Лучшая для ТМ», «Фаворит-обманка», «Кто сливает третий период», «Дома / в гостях»; каждая — КХЛ и НХЛ.
- Минимум матчей для попадания в список (допущение: 15 КХЛ / 20 НХЛ), иначе шум малой выборки.

## Общее для обоих
- **Хуки (1,5 с, прогнать через `ig-human`):** «Эта команда КХЛ тихо губит тоталы весь сезон. Номер один — в конце»;
  «5 команд, на которые не стоит рассчитывать в тотале больше»; «Твоя команда в этом списке? Проверь до последнего места»;
  «Лучшая команда недели — не та, о которой ты подумал».
- Счётчик «5 из 5 → 1 из 5». В конце вопрос «Какая команда должна быть шестой?» и подвал Telegram (`core.footer`).
- 21–24 с, треки владельца (`render/reels/owner_tracks.py`, дропы — `render/track_sync.py`); кадр заполнен по высоте
  (`team/RULES.md` «Ролики»); @jarvibet внизу; без БК, промокодов, гарантий, «шансов» в процентах.
- SEO-пакет к каждому ролику (описание, 3 хештега, поисковые фразы — `ig-caption`), файлом владельцу + в сессию руководителя.

## Что сделать
1. `team/reels_weekly/data.py` — скрипт данных: КХЛ — приложение КХЛ (`team/picks/khl_data.py`, `khl_hist.py`),
   НХЛ — API НХЛ (`nhl_data.py`, `nhl_hist.py`); игровой день НХЛ — по Нью-Йорку. Недельные топы и сезонные доли -> JSON.
2. Проверка данных: сверка 2–3 цифр с официальным источником, тест на фикстурах (как `team/daily/test_daily.py`).
3. Шаблоны в `render/reels/` на основе `top3.py` (отсчёт, переход «сквозь цифру»), `race.py` (счётчик/гонка), `results.py`
   (итог «зашло X из Y»): новый модуль `weekly.py` + сцена скрытого №1 (размытая эмблема -> резкая на дропе).
   Скилл `jarvis-video` собирает, кадры локально, ролик — в Actions; смотреть 2–4 кадра.
4. Workflow `.github/workflows/reels-weekly.yml` (понедельник утром, данные -> рендер -> SEO -> владельцу в бот через
   `itogi.yml`/`jarvis-send`); антирейтинг — по очереди выпусков. Образец — `team/reels_daily/`, `team/postmatch/`.
5. Первый пробный выпуск: «Худшая команда КХЛ для тотала больше» — владельцу в бот черновиком.
6. После 7–10 дней — снимок Instagram (`ig-audit`): досмотр, охват, сохранения; сравнить с роликами дня.
7. Записать в `team/NOW.md`, `team/LOG.md`; в `team/reels_weekly/README.md` порядок очереди тем.

## Правила
Прогнозы и кэфы — только черновиком владельцу, в канал не отправлять; в `main` — только через PR; без выдуманных цифр
(любая цифра на экране — из выгрузки); команды на экране с эмблемами без обводки (`render/reels/icons`), тёмный фон/золото
или светлый стиль `top3` — по выбору `frontend-design` (допущение).

## Готово, когда
Скрипт данных отдаёт верный топ за прошлую неделю и сезонный антирейтинг (цифры сверены); ролик КХЛ и НХЛ 21–24 с
собраны в Actions; владелец получил файл + SEO в боте; №1 раскрывается на дроп; итог «зашло X из Y» совпадает с `PICKS.md`.

## Спросить у владельца
Нет, можно начинать. Уточнить по ходу: подходит ли порог выборки (15/20 матчей); оставить ли «Фаворит-обманку»
(нужна линия кэфов, берётся из `khl_data.py` / `pin.py`, исторические кэфы могут отсутствовать — тогда считать по
сыгранным матчам и честно подписать).

## Скиллы и инструменты
`jarvis-video`, `jarvis-video-analyst` (заставки), `ig-reel`, `ig-caption`, `ig-human`, `jarvis-send`, `jarvis-postmatch`
(как образец данных), `frontend-design` + `impeccable` для кадров.
