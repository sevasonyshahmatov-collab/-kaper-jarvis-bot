# Недельные ролики: «Топ недели» и антирейтинги сезона (владелец 30.10)

ТЗ — `BRIEF.md`. Шаблон — `render/reels/countdown.py` (отсчёт 5→1, №1 скрыт золотым размытым силуэтом и открывается
на дроп трека, счётчик «5 из 5 → 1 из 5», итог наших прогнозов недели, вопрос «Какая команда должна быть шестой?» +
плашка Telegram). Данные — `weekly_data.py` (приложение КХЛ / API НХЛ через `team/daily/data.py`; итог прогнозов — опубликованные
ставки владельца с его правками, расчёт `team/daily/settle.py`). Сборка и отправка владельцу — `make.py` в Actions:

    задание team/out/<день>/<имя>.json: {"day": "…", "make": ["team/reels_weekly/make.py under khl 2026-10-30"], "messages": []}
    → itogi.yml (скилл jarvis-send). Локально — только кадры: make.py … --spec=данные.json --frames=1,5,15

Треки (как в `team/reels_daily/make.py`): антирейтинг — too_fast (дроп 33,58 с), топ недели — militant (29,73 с).
Длина ~22–23 с, №1 на ~15–16,5 с.

## Очередь тем
- «Топ недели» (пн, за пн–вс, КХЛ и НХЛ отдельно): 1) самые результативные команды (`week`) — готово;
  2) лучшие бомбардиры недели; 3) лучшая серия — по очереди из недели в неделю (2 и 3 — сделать).
- Антирейтинги (по одному в неделю, обе лиги): 1) «Худшая для тотала больше 5,5» (`under`) — готово; дальше «Лучшая для ТМ»,
  «Фаворит-обманка» (нужны кэфы — проверить, есть ли история линии), «Кто сливает третий период», «Дома / в гостях».
- В очередь автозапуска — после «да» владельца по первым роликам. Сравнение — через 7–10 дней по снимку Instagram
  (время просмотра, охват не-подписчиков, сохранения) против роликов дня тех же дат.
