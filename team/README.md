# Команда JARVIS — как она устроена

Команда ИИ-агентов, которая каждое утро сама работает на продвижение канала @jarvibet и доработку таблиц КХЛ/НХЛ.
Руководитель — Claude: ставит задачи, раздаёт их ролям, проверяет и отчитывается владельцу в Telegram.

## Состав

| Роль | Файл | Что делает |
|---|---|---|
| Руководитель | `LEAD.md` | планёрка, распределение задач, контроль, отчёт владельцу, публикация |
| Стратег продвижения | `roles/strategist.md` | цели и план недели, рубрики, идеи роста, задания (бриф) остальным |
| Аналитик | `roles/analyst.md` | факты дня: расписание, результаты, прогнозы модели, «что заходит» |
| Копирайтер | `roles/copywriter.md` | тексты постов, подписи, опросы — по правилам канала |
| Дизайнер | `roles/designer.md` | баннеры и ролики набором `render/` по брифу |
| Разработчик | `roles/developer.md` | доработки таблиц, бота, автоматики — только через PR |
| Контроль качества | `roles/qa.md` | проверка правил, цифр, орфографии перед отправкой |

Агенты не пишут друг другу напрямую: руководитель передаёт задачи и результаты, общая память — файлы этой папки.

## Распорядок

- **Каждое утро ~09:45 МСК** — автозапуск (Routine «Команда JARVIS — утренняя планёрка»): `LEAD.md`, шаги 0–7.
- **По понедельникам** стратег дополнительно обновляет `PLAN.md` (план недели) и подводит итоги прошлой.
- Владелец может дать задачу в любой момент: строкой в `INBOX.md` (через GitHub или попросив Claude в чате) —
  руководитель возьмёт её на ближайшей планёрке.

## Куда что идёт

- Владельцу в Telegram (личка с ботом): отчёт планёрки, черновики, идеи, вопросы — каждый день.
- В канал @jarvibet — только рубрики из списка «можно публиковать самим» (`RULES.md`), после проверки качества,
  не больше двух постов в день. Прогнозы и кэфы — только черновиками владельцу.
- Доработки таблиц и бота — PR в `main`; вливает владелец (изменения в `apps-script/` за 5–7 минут попадают в живые таблицы).

Отправка в Telegram — через GitHub Actions (облачные сессии до Telegram не достают): задание `out/<день>/job.json`,
запуск `itogi.yml` с `{"kind": "team", "job": …}`, код — `render/team_job.py`.

## Файлы

`GOALS.md` — цели · `PLAN.md` — план недели · `BACKLOG.md` — задачи · `INBOX.md` — поручения владельца ·
`PICKS.md` — опубликованные прогнозы владельца (для итогов) · `LOG.md` — журнал планёрок · `out/<день>/` — материалы дня
(тексты, бриф, `make.py`, `job.json`; картинки в репозиторий не кладём — их рисует задание в Actions).
