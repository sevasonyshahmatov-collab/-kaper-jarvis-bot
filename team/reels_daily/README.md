# Конвейер шортсов КХЛ

Задание: `docs/handoff/CONVEYOR.md`. Шаблоны: `team/reels_selected/README.md`. Claude в ежедневной работе не участвует:
всё считается и собирается в GitHub Actions (`.github/workflows/reels-daily.yml`).

## Что делает один запуск
1. **plan** — матчи дня, сыгранные матчи и линия Фонбета из приложения КХЛ (`team/picks/khl_data.py`), линия Pinnacle
   (`team/picks/pin.py`), «Что заходит» по каждой паре (`team/picks/calc.py`).
   Прогноз (`pick.py`) — правило владельца 17.10: самое вероятное событие (от 45 %) с кэфом **1,6–2,3**; среди ставок в
   пределах 4 п. п. от лучшей — кэф под матч: равный (П-меньший/П-больший ≥ 0,75) — 1,6–1,7, аутсайдер против сильного
   (< 0,5) — 1,8–2,0. В один день — по возможности разные виды ставок. Нет такой ставки или линии — матча в роликах нет.
   Роликов не больше `max` (по умолчанию 6): самые уверенные прогнозы. Владельцу — список матчей дня с прогнозами.
2. **render** (по 3 ролика на задание, задания идут параллельно) — шаблон 14.10 по кругу (начало круга сдвигается по
   дням); прогноз на тотал — «Эфир» (в финале обе команды). Форма клубов — `form.py`. Две версии: со звуком и `_clean`.
   Владельцу в Telegram: ролик + в подписи название и описание для YouTube с хэштегами (`texts.py`), следом версия без музыки.
3. Ролики — артефакт запуска на **2 дня**, потом GitHub удаляет их сам. В репозиторий не кладём.

## Запуск
- По расписанию: 06:20 МСК (работает, когда `reels-daily.yml` есть в основной ветке `main`).
- Вручную: Actions → «Шортсы КХЛ — конвейер» → Run workflow (день, сколько роликов); из бота/таблицы — `repository_dispatch`
  типа `reels` с `{"day": "ГГГГ-ММ-ДД", "max": 6}`; из ветки `claude/**` — изменить первую строку `team/reels_daily/RUN`
  (день) и запушить.
- Проверка кадрами без треков и Telegram: `python team/reels_daily/make.py plan <день>` (нужен доступ к API КХЛ), затем
  `PYTHONPATH=render python team/reels_daily/make.py render <день> --part 1 --frames 2,9,15,20` → `out/reels_daily/<день>/`.
