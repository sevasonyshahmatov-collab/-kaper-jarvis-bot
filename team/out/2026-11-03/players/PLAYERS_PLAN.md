# Раздел «Игроки» — разбор oddalerts.com/players и план (03.11)

## Что у них (oddalerts.com закрыт для облака — по выдаче поиска)
- Страницы по метрикам: голы, удары, удары в створ; по лигам (АПЛ, Ла Лига, ЛЧ…) — итоги и «на 90 минут», ещё блоки, отборы, передачи.
- Фильтры и бэктест, алерты, CSV и API — платно: Pro ~£19.99/мес, с API ~£69.99/мес, сезон ~£179.99. Бесплатно — тренды и часть вероятностей.
- Поставщик данных не раскрыт (вероятно Sportmonks или аналог — догадка). Раз продают API — копирование и парсинг запрещены.

## Копировать нельзя — делаем своё
Их данные, тексты, вёрстку и дизайн брать нельзя (условия сайта, авторское право, данные куплены у поставщика). Идею «n из N по игрокам» — можно, на своих источниках и в своём оформлении.

| Показатель | У них | Мы | Источник | Сложность |
|---|---|---|---|---|
| Голы, пенальти, «забил в n из N» | да | есть (прототип) | ESPN, уже собираем | готово |
| Карточки «n из N» | да | есть (прототип) | ESPN | готово |
| Дом/выезд, форма 10 матчей, след. соперник | частично | есть (прототип) | ESPN | готово |
| Минуты, выход в старте (N = матчи игрока) | да | можем | ESPN summary (составы) | средне |
| Удары, удары в створ, фолы, ассисты по игроку | да | можем | ESPN summary — статистика игрока в матче | средне |
| Против конкретного соперника | да | можем | ESPN, прошлые сезоны | средне |
| xG по игроку | да | нет бесплатно | FBref убрал данные Opta (01.2026); Understat — условия не ясны | нельзя / рискованно |
| Отборы, передачи, блоки | да | частично | ESPN summary (не во всех лигах) | средне |
| Хоккей: голы, очки, броски, TOI, «2+ броска» | — | можем | НХЛ api-web.nhle.com, КХЛ khl.api.webcaster.pro | средне |

FBref: лимит ~10 запросов/мин, бан IP, условия против публикации — из Actions не берём.

## Что делаем первым
1. Сборщик ESPN summary по каждому матчу: составы, минуты, удары, в створ, фолы, ассисты — N станет «матчи игрока».
2. Рынки: «забьёт», «2+ удара», «1+ в створ», «гол+пас», «карточка»; фильтр «не меньше 60 минут».
3. Блок «Против следующего соперника» и ссылки с карточки игрока на страницу клуба (football/team.html).
4. Хоккей — тот же раздел: НХЛ (очко, 3+ броска, TOI), КХЛ (очко, броски из протоколов).
5. Обновление раз в день после матчей через Actions; страница игрока — позже.

Прототип: ветка claude/team-dev-site-v3a, football/players.html (+ assets/players.css/js, data/players.js, сборщик football/players_build.py).
