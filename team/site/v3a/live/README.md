# Живой счёт (макет v3a)

Что есть: `assets/live.js` + `assets/live.css`. Браузер посетителя сам раз в 30 с берёт счёт из открытого источника и показывает «LIVE», счёт, период или минуту; гол — короткая подсветка счёта (при `prefers-reduced-motion` без анимации, только цвет); после финала — «Финал». Кэфов в лайве нет: на странице матча блок «Кэфы на матч» на время лайва скрывается.

Где работает: страницы матчей (`khl/…`, `nhl/…`, `epl/…` и др. — блок `.lv-box`), «Прогноз на сегодня» по лигам (`hockey/forecast-*.html`, `football/forecast-*.html` — строки `li.fc-m`), «Мои матчи» (`me/`, строки `.me-m` во время матча). Общий хаб `forecast.html` матчей не перечисляет, скрипта на нём нет. Разметка: атрибуты `data-lv`, `data-lv-lg`, `data-lv-t` (начало ISO), `data-lv-h`/`-a` (id клубов), `data-lv-hn`/`-an` (названия) — их ставят `seo/build_seo.py` (`lv_attrs`) и `seo/build_match.py`, а в «Моих матчах» `assets/me.js`.

Правила опроса: только когда вкладка видна (`visibilitychange`); только в окне матча — от начала по расписанию до 3,5 ч после (до 6 ч, если источник ещё отдаёт «идёт»); у матча со статусом «финал» опрос прекращается; вне окна запросов нет. Три неудачных запроса подряд — плашка прячется. Вывод только через `textContent`. Выключить целиком: `window.JV_LIVE_OFF = true` до подключения скрипта.

## Источники (проверка из GitHub Actions: `sources_report.md`, `check_sources.py`, запуск — изменить `check_run`)

| Лига | Источник | CORS из браузера | Что отдаёт |
|---|---|---|---|
| НХЛ | ESPN `site.api.espn.com/apis/site/v2/sports/hockey/nhl/scoreboard?dates=ГГГГММДД` (дата по востоку США) | да, `*` | счёт, период, время периода, статус |
| АПЛ, Ла Лига, Серия А, Бундеслига, Лига 1, РПЛ, ЛЧ, ЛЕ | ESPN `…/soccer/<eng.1, esp.1, ita.1, ger.1, fra.1, rus.1, uefa.champions, uefa.europa>/scoreboard?dates=ГГГГММДД` (UTC) | да, `*` | счёт, минута, статус (перерыв, доп. время) |
| КХЛ | приложение КХЛ `khl.api.webcaster.pro/api/khl_mobile/events_v2.json?…&stage_id=407` | да, но только для списка событий: с `Origin` его `data.json` и `event_v2.json` отвечают 403; `events_v2` отдаёт `ACAO` равный нашему origin | счёт, статус, период; минуты в списке нет |

Не годятся: API НХЛ `api-web.nhle.com` (без `Access-Control-Allow-Origin`, браузер блокирует), `api.nhle.com` (то же), сайт khl.ru (без CORS). Preflight `OPTIONS` у ESPN отвечает 403, но запрос GET без своих заголовков preflight не вызывает, поэтому работает.

Что не проверено (в момент проверки не было идущих матчей): значения `game_state_key` КХЛ для «идёт»; сейчас «идёт» = любое, кроме `finished` и слов «не начат / анонс / отмена»; ESPN live-формат проверен по документированным полям и подменой ответа. Номер стадии КХЛ `KHL_STAGE=407` зашит в `live.js` (из `data.json` его с браузера не взять); к плей-офф обновить.

## Что уходит третьим сторонам (для 152-ФЗ)

Каждый опрос — запрос браузера посетителя на иностранный сервис: ESPN (США, Disney) и приложение КХЛ (webcaster.pro). Им видны IP-адрес посетителя, User-Agent и время запроса, адрес страницы не передаётся (`referrerPolicy: no-referrer`; куки не отправляются, `credentials: omit`). Это тот же класс вопроса, что Google Fonts в SECURITY_0411: передача IP за границу без согласия. Пока сайт в макете, допустимо; при запуске либо переносим на Worker (ниже), либо указываем в политике обработки данных. Также: источники — неофициальные, без договора; ESPN может закрыть CORS или поменять формат без предупреждения.

## Перенос на Cloudflare Worker (при запуске)

1. Worker `live.<наш домен>`: по `GET /?lg=<лига>&d=<дата>` берёт те же источники на сервере (КХЛ с нужными заголовками, НХЛ можно напрямую из `api-web.nhle.com`, он на сервере без CORS-проблемы), кэширует ответ в Cache API на 10–15 с (один запрос к источнику на всех посетителей вместо одного на каждого) и отдаёт единый короткий JSON `{id, k: live|final, hg, ag, st}` с `Access-Control-Allow-Origin` нашего домена.
2. В `live.js` заменить `espnUrl`/`khlUrl` на адрес Worker, а `fromEspn`/`fromKhl` — на чтение единого JSON (сопоставление клубов можно перенести в Worker).
3. Посетитель общается только с нашим доменом: IP не уходит иностранным сервисам, вопрос 152-ФЗ снимается; заодно проходит КХЛ с минутами и можно подключить `api-web.nhle.com` (даёт точнее ESPN).
