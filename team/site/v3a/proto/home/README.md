# Новая главная: три шаблона

Все три берут те же данные, что `index.html` (ближайшие матчи, вероятности модели, кэфы; общий помощник — `common.js`). Шрифты как на сайте: Inter (`--display`) и Literata. Стеклянного табло нет, названий БК нет. Смотреть: `team/site/v3a/proto/home/<код>/index.html` (из папки `team/site/v3a`: `python3 -m http.server`).

- **a — «Первая полоса»** (светлая палитра c). Матч дня набран как газетный заголовок: две эмблемы, крупные названия, цифры модели под ним. Ниже спокойные колонки «Хоккей» и «Футбол» с линейками. Отличие: главный образ — крупный шрифт с засечками как заголовок, всё остальное тихое.
- **b — «Рейтинг уверенности»** (ночная палитра a). Первый экран — сам список матчей, выстроенный по уверенности модели; в каждой строке полоса П1 / Х / П2, кэфы и главный исход. Переключатели «Все / Хоккей / Футбол» и «По уверенности / По времени». Отличие: нет героя-баннера, список и есть главная.
- **c — «Стена эмблем»** (синяя палитра b). Плитки матчей: каждая собирается из двух эмблем, крупная плитка — матч дня. Под эмблемами один исход модели. Отличие: главный образ — клубы, а не цифры и не текст.
