# Эфир на весь сайт — статус (ведущий дизайнер, 06.11)

Включение: `?theme=efir` (запоминается в sessionStorage до закрытия вкладки), `?theme=off` — сброс. Без параметра сайт как раньше.
Загрузчик `assets/efir/efir-loader.js` стоит в `<head>` ПЕРЕД `assets/palettes.js` на всех html и в `seo/build_seo.py` (patch_text и шаблон forecast). При теме старый переключатель палитр выключен.

## Решения
- Шрифт: Unbounded (заголовки, цифры) + Onest (текст) + **IBM Plex Sans Italic 500** (курсивный акцент) — наклон ≈12°, как у клиньев и скошенных кнопок; настоящий кириллический курсив, читается на цветных клиньях. Playfair, Literata, Unbounded Light — см. `shots/font_sheet.png`. Шрифты локально: `vendor/`.
- Фон: «сталь студии» #2c374d, мягкий свет сверху #4a5b7a, два еле заметных клина цвета матча дня. Контраст (по пикселям главной): основной текст 7,7 · второй 5,9 · приглушённый 5,2 (нужно ≥ 4,5). См. `shots/bg_sheet.png`.
- Плашки: только у интерактива — карточка матча, строка-титр, кэф, табло-счёт, кнопка, чип. Тексты, пояснения, вопросы, итоги, подписки — открытая типографика (линии, крупные цифры-контуры, клин клуба как акцент, воздух). До/после — `shots/plates_before_after.png`.
- Источник кэфов не называется: «Линия обновляется дважды в день» (в теме; из строк матчей подпись «Линия: …» убирается).

## Для следующих агентов: что есть в efir.css (префикс `ef-`, всё под `html.efir`)
Токены: `--ef-bg --ef-spot --ef-ink --ef-mute --ef-dim --ef-line --ef-chip --ef-chip2 --ef-row --ef-glass --ef-d --ef-b --ef-i --ef-gut --ef-maxw --ef-sec --ef-tan --ef-ease --ef-sh1 --ef-sh2`; клубные `--hd --hb --ad --ab` (ставит JS). Токены сайта (`--paper --ink --card --display --text --signal`…) переопределены под Эфир — старые страницы уже в теме.
Компоненты: `.ef-tag` (+`--dark`, обёртка `.ef-tagw`) — эфирная метка раздела («ФОРМА · ПОСЛЕДНИЕ 5»); `.ef-wedge`, `.ef-wedge--a`, `.ef-rule` — клин и линия-разделитель; `.ef-glass` (+`__top __names __clock __p __foot`) — стеклянная плашка-счёт; `.ef-gl` — блик при наведении; `.btn/.btn-tg/.btn-ink/.ef-btn(--ghost)` — белая скошенная кнопка с заездом клина клуба, нажатие scale .97; `.ef-chip` — чип-фильтр; `.ef-row` (+`.w--h/.w--a`) и `.hm-row` — строка-титр матча; `.ef-odd` (+`.fav`) — кэф; `.ef-seg` — столбик долей; `.ef-open`, `.ef-lines`, `.ef-bignum`, `.ef-lead`, `.ef-sechead` — открытая типографика; `.ef-it` — курсивный акцент; `.ef-rv` (+`--line`, `style="--i:N"`) → `.ef-in` — появление при прокрутке; `.ef-stage` (+`__big __em --h/--a __nm`, `.wedge--h/--a`) — сцена матча; шапка (`.hd .logo`, `.ef-air`, `.seg`), подвал `footer.jvf`; View Transitions `.ef-vtw` (клин + перелёт эмблем `em-h/em-a`).
Правила для «обычных» блоков сайта (без новой разметки): `.obj`, `.steps`, `.soon`, `.sub`, `.faq`, `.tgbar` уже переделаны без плашек.
`efir.js` → `window.JVEfir`: `cols(m)` цвета клубов матча, `cv(c)` строка стилей, `emUrl`, `scramble(el,final,ms,delay)` пересчёт цифр (`[data-num]` в `.ef-rv` считается сам), `reveal(root)`, `setPageColors(m)`, `tag(text)`, `pair`, `mot`. Данные: `JV_TODAY/JV_MODEL/JV_LINES`, `CLUB_SET` (грузится из `assets/club/themes.js`).
Как переносить страницу: поставить цвета (`JVEfir.setPageColors(m)`), добавить `.ef-tag` перед h2, карточки-текст превратить в открытые блоки (`.ef-open`/линии), оставить плашки только у интерактива, строки матчей — `.ef-row`.

## Общие страницы (matches, model, glossary, forecast, me, 404, поиск, шапка/меню, LIVE, избранное) — 06.11
Правила — `pages-common.css`, оформление без правки разметки — `pages-common.js` (подключены через `efir-loader.js`; JS ждёт `window.JVEfir`).
- **matches.html** — колода: карточка = «следующий матч» в эфире (два клина клубов с белыми рёбрами, эмблемы без кружков, стеклянная нижняя часть, кэфы-плашки, блик и сдвиг клина при наведении, нажатие .97); цвет фона и клиньев следует за карточкой впереди; «О встрече» — открытая типографика (линии, клин-акцент, квадратные полосы вероятностей); фильтр и стрелки — скошенные чипы; панель статистики — сталь.
- **model.html** — метки разделов, три шага с клиньями (без плашек), «Как считаем» с линиями, живой пример: цифры 2,42/2,74 крупно, полосы без скруглений, таблица линиями; «Чего не знает», вопросы — линии в две колонки; подписка с клином.
- **glossary.html / forecast.html** — оглавление чипами, термины открытыми блоками с клином над линией; хабы лиг и строки матчей лиг (`.fc-m`) — строки-титры с клиньями.
- **me/** — открытая «пусто» с клином, чипы-клубы, карточки клубов и матчей — плашки с клином, «Вход и подписка» без плашки.
- **404, поиск (оверлей), шапка (gnav, меню, звёздочка), LIVE, избранное** — те же правила. Шапка с разделами: часы эфира сворачиваются на ≤1700 px (иначе горизонтальный скролл), на ≤1000 px скрыты; на ≤400 px логотип и кнопка уже, на ≤350 px у кнопки Telegram только значок.
- Правка общего: `efir-loader.js` — в список CSS добавлен `pages-common.css`, после `efir.js` грузится `pages-common.js`.
