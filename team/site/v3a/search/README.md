# Поиск по сайту v3a

Индекс собирается так: `python3 team/site/v3a/search/build_index.py` (из корня репозитория, без сети) -> `team/site/v3a/data/search.json` (до 150 КБ).
Читает `assets/data/teams.js`, `football/data/football.js`, `hockey/data/{nhl,khl}_players.json`; матчи берёт за 7 дней назад и 7 вперёд от текущей даты (МСК). Для ежедневного конвейера — вызвать после обновления данных.
Синонимы клубов (EN, «Барса», «Ман Сити») — словари `KHL`, `NHL`, `FOOT` в начале скрипта.

Клиент: `assets/search.js` (подключается из `assets/nav.js`, стили в `assets/search.css`). Открытие: лупа в шапке, `/` или Ctrl+K. Индекс грузится при первом открытии.
Группы: Клубы · Матчи · Лиги · Игроки (только хоккей; футбольные игроки скрыты).
