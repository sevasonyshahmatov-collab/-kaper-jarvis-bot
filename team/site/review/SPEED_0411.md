# Скорость сайта v3a, 04.11 — замер до / после

Условия: Playwright + Chromium, iPhone 13, сеть «Fast 3G» (CDP: 1,6 Мбит/с вниз, задержка 562 мс), CPU ×4, кэш выключен, сервер со сжатием gzip
(как GitHub Pages). Внешние картинки (ESPN, nhle, khl.ru, Wikimedia) и шрифты не грузятся из облака и не учтены. Лучший из двух прогонов.
«Вес» — сумма ответов своего сервера по сети (gzip), КБ; «в распакованном виде» — после распаковки (то, что парсит телефон).
«Первый блок» — когда на странице появился первый блок содержимого (шапка клуба / табло / первая карточка списка), мс.
LCP у всех страниц ≈ 1,6 с: это первый экран текста, его определяет CSS и шрифты, а не данные — данными он не менялся.

## Что сделано
- `daily/split.py` (шаг `split` в `daily/run.py`, перед `search`; запуск в Actions проверен: run 3 зелёный, файлы закоммичены ботом):
  - хоккей: `assets/data/teams-lite.js` (без pl/h2h/picks, 111 КБ вместо 509) + `assets/data/club/<slug>.js` (pl/h2h/picks клуба, ~2 КБ gzip);
  - футбол: `football/data/football-lite.js` (135 КБ вместо 724) + `games.js` (матчи всех клубов — главная, ЛЧ, лиги) + `club/<id>.js` (матчи, бомбардиры, карточки клуба и соперников ближайших матчей, личные встречи);
  - игроки футбола: `football/data/pl/<лига>.js` (топ-15 бомбардиров, топ-10 карточек) и `pl/trends.js` (4 поля) — players.js (1,8 МБ) больше не грузится нигде, кроме скрытого раздела «Игроки» и photo-credits;
  - игроки хоккея: `hockey/data/plite_{khl,nhl}.json` (короткий лог, TOI целыми секундами) и `hockey/data/players/<slug>.json` (фото игроков клуба, ~1 КБ вместо 0,9 МБ на странице клуба).
- Страницы клуба подключают файл клуба через `document.write` + `preload` в `<head>` (параллельная загрузка).
- Картинки: эмблемы футбольных клубов `assets/fc` 384 → 192 px (4,1 → 1,6 МБ), фон шапки клуба 2000 → 1400 px (557 → 191 КБ); `width/height` у эмблем на главной хоккея.
- Анимации: на телефоне (малый экран + касание) частицы — вдвое меньше, 1:1 пиксель, ~30 к/с, первый кадр после load; фон шапки клуба — один статичный кадр; GSAP/SplitText не грузятся (и preload только от 621 px); `emb/clubbg/titles` — `defer`. prefers-reduced-motion обрабатывался и раньше. Тема arena (свет при прокрутке, JV.lit) не менялась.
- Горизонтальная прокрутка на телефоне была на всех страницах до правок (шапка шире экрана на 33 px; табло футбола) — исправлено в `nav.css`, `v3a.css`.
- Шрифты: `display=swap` уже стоял на всех страницах.
