## Проверено — чисто

1. **Секреты**: grep по всему дереву и `git log --all -p` (79 коммитов) — токены Telegram, `ghp_/github_pat_/gho_`, `AIza`, `sk-`, `AKIA`, `script.google.com/macros`, `spreadsheets/d/`: **0 совпадений**. Chat_id владельца, e-mail владельца в файлах сайта, IP — нет.
2. **Apps Script / таблицы**: адресов веб-приложений и ID таблиц на сайте нет; `team/site` в публичный репо ничего про `apps-script/` не копирует.
3. **Личные данные**: в `stats/*.json` и `app/data.json` — только данные постов канала (ставка, кэф, счёт, номер поста), результат в «единицах» (flat-stake), без банка и сумм владельца. Имена в `app/data.json` — тренеры и игроки КХЛ/НХЛ (публичные данные лиг). Путей сессий, ссылок на чаты Claude, имён внутренних веток нет.
4. **Лишние файлы**: `.env`, ключей, бэкапов, `.git` внутри, source maps, probe-папок (`team/site/app_data/probe_out`) на сайте нет; копируются только `site.css`, `og.jpg`, `app/` (шесть фонов, 16 эмблем).
5. **Два `*.txt` в корне**: `49a63117…txt` и `cc8724be…txt` — вместе это один ключ IndexNow (32 hex = `sha1(адрес сайта)[:32]`, `build.py:657-658`). Он по замыслу публичен; секрета не содержит. Файл ключа лишь подтверждает владение доменом для Яндекса. (Лишний: из-за правки базового адреса один ключ записан в двух файлах после смены домена — старый можно удалить.)
6. **README.md** — одно слово «jarvibet». **404.html** — `noindex`, без внутренних данных. **sitemap.xml** — только публичные страницы. `app/` — `noindex`.
7. **Внешние ресурсы**: Google Fonts (стили), cdnjs/jsdelivr (анимации), telegram.org (Mini App), khl.ru (картинки арен), t.me/youtube/instagram (ссылки). Счётчиков аналитики, iframe и форм нет. Смешанного контента нет.
8. **`target="_blank"`**: все ссылки с `rel="noopener"`; `window.open(..., 'noopener')`.
9. **XSS**: параметров `?id=`/`?theme=` нет. Единственный ввод из URL — хэш `#match/…`, `#team/…`, `#trends/…`; он используется только как ключ поиска в данных (не найден — показывается список), в HTML не подставляется. Данные из JSON в приложении экранируются `esc()` (44 места); неэкранированные подстановки — числа и цвета из своего генератора. `JSON-LD` экранирует `</`. Эхо данных без `esc` возможно только если сломается источник данных (КХЛ/НХЛ), это учтено как риск низкий.
10. **Публикация**: `site.yml` запускается только по расписанию, `workflow_run` и вручную — нет `pull_request`/`pull_request_target`, форк секреты не получит. `permissions: contents: read`; токен `SITE_TOKEN` — fine-grained, по README только на репо сайта; вход `day` проверяется регулярным выражением, `inputs` идут через `env`. Копируется в публичный репо только вывод `build.py`.
11. **Страницы без поста** удаляются (`SITE убрано страниц без поста в канале`), в HTML и `app/data.json` действует `channel_view` — прогнозы видны только после поста (утечка только в сыром `data/*.json`, см. #1).
