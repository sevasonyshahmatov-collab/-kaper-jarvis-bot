# Архив: старая автоматика на GitHub (не используется)

Здесь лежат первые версии бота на Python, которые запускались через
GitHub Actions. С сентября 2026 вся автоматика работает в Apps Script
таблицы (см. `apps-script/`), а эти задачи были выключены вручную:

| Файл | Что делал | Чем заменено в Apps Script |
|---|---|---|
| `post_daily_coupon.py` | утренний пост прогнозов в Telegram | посты «матчи дня» и лист «Посты» |
| `scout_upcoming_matches.py` | новости перед матчами через Claude → лист «Контекст и новости» | «Разведчик», «Агент», листы «Факты» и «Досье_команд» |
| `update_stats.py` | броски и вратари с QuantHockey (отвечал 403) | лист «Статистика_КХЛ» из официального приложения КХЛ |

Файлы задач лежат в `archive/workflows/`, а не в `.github/workflows/`,
поэтому GitHub их больше не видит и не запустит — ни по расписанию, ни кнопкой.
Не переносите их обратно: `update_stats.py` перезаписал бы столбец K
листа `Data`, а `post_daily_coupon.py` отправил бы в канал второй пост.
