# Архив роликов

Решение владельца 17.10: **каждый ролик сохраняется**. Здесь — сжатые копии (720×1280, ~1 МБ) всех роликов, которые
делались, по папкам в порядке работы. Сжимает и кладёт сюда `tools/video_archive.py`; GitHub Actions дополнительно
хранит полные версии роликов, которые рисует, 90 дней (артефакт «videos» у запуска).

## Утверждённые владельцем форматы
- 11.10: «Купон» (coupon), «Чат» (chat), «Топ-3» (top3) — `09_reels_серия2_доработка_и_новые/`.
- 12.10: «Состав» (lineup), «Сравнение» (tape), «Терминал» (jarvis), «Карточка» (card) — `13_утверждённые_1210/`.
- 14.10: «Приборка», «Кино»⭐, «Граффити», «Эфир»⭐, «Ювелир», «Кинетика», «Скачки», «Радар», «VHS» — `14_утверждённые_1410/`.

Ролики 12.10 и 14.10 сначала не сохранились (жили только во временной среде) и были собраны заново 17.10
тем же кодом, с теми же матчами и треками.

Описание роликов 10–11.10 — `ЧТО_ЗДЕСЬ_10-11.10.md`.
