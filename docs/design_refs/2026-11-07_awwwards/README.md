# Ролик-референс владельца 07.11 (Reels @eduardtr94, 68 с) — «где искать референсы сайтов»
Источник примеров — awwwards.com (Sites of the Day, фильтры по категории и цвету). Кадры: `frames_detail.jpg`, `sheet_2.jpg`, `sheet_3.jpg`.

Два сайта из ролика:
1. «Отвал башки» (студия Silencio / Visual Languages): светло-серый монохром, белые 3D-предметы (банка, упаковки) парят и
   вращаются, огромный тонкий гротеск «DIGITAL PRODUCTS FOR CONTEMPORARY BRANDS», мелкий моноширинный текст колонками.
   Главный приём — «чек — главный герой»: при прокрутке растёт/печатается кассовый чек со строками услуг.
2. «Главный экран = космос» (агентство web3): тёмный ч/б, медленная абстрактная 3D-лента (гофра) в дымке, зерно,
   крупный заголовок с курсивом («Powering the *next* generation…»), минимальное меню-пилюля, одна кнопка.
