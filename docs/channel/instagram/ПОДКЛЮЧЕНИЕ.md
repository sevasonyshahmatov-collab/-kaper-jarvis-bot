# Instagram: подключение автозагрузки роликов (19.10)

Способ — «Instagram API со входом через Instagram» (страница Facebook не нужна). Ключи — только в GitHub Secrets,
в чат не присылать. Экраны Meta меняются: если не совпадает — скриншот в чат.

## Шаг 1. Аккаунт (телефон, 5 мин)
1. Новый аккаунт Instagram, ник `jarvibet` (занят — `jarvibet_hockey`), имя «JARVIS | Прогнозы на хоккей».
2. Аватар — `docs/channel/youtube/final/аватар_800x800.png`.
3. Описание: «Прогнозы на КХЛ и НХЛ каждый день · Все прогнозы — в Telegram» + ссылка https://t.me/jarvibet.
4. Профессиональный: Настройки → «Тип аккаунта и инструменты» → «Переключиться на профессиональный» → «Автор» → «Спорт».

## Шаг 2. Приложение Meta (компьютер, 10 мин)
1. developers.facebook.com → «Начать» → вход через Facebook (нет — создать) → подтвердить телефон/почту.
2. «Мои приложения» → «Создать приложение» → название `JARVIS Shorts` → сценарий «Управление сообщениями и контентом в Instagram» → бизнес-портфель не выбирать → «Создать».

## Шаг 3. Тестировщик (2 мин)
1. В приложении: «Роли приложения» → «Роли» → «Добавить людей» → «Тестировщик Instagram» → ник аккаунта.
2. В Instagram (сайт, с компьютера): Настройки → «Сайты и приложения» → «Приглашения тестировщиков» → «Принять».

## Шаг 4. Ключ (5 мин)
1. В приложении: «Сценарии использования» → Instagram API → «Настройка API со входом через Instagram».
2. «Создайте маркеры доступа» → «Добавить аккаунт» → войти в Instagram проекта → «Разрешить» (публикация контента).
3. Скопировать маркер (длинная строка) и ID аккаунта Instagram (число рядом).
4. GitHub → Settings → Secrets and variables → Actions → New repository secret: `IG_TOKEN` — маркер, `IG_USER_ID` — ID.

Маркер живёт 60 дней; конвейер напомнит в Telegram за неделю до конца — повторить шаг 4.

## Шаг 5. Проверка
Написать в чат «готово» — пробная загрузка одного ролика.
