# Оформление YouTube — «Гроза + клубы» (выбор владельца 17.10)

Файлы:
- `RU_баннер_2560x1440.jpg` — баннер русского канала (КХЛ + НХЛ, эмблемы клубов обеих лиг).
- `EN_banner_2560x1440.jpg` — баннер англоязычного канала (только НХЛ, эмблемы клубов НХЛ).
- `аватар_800x800.png` — аватар (один для обоих каналов).

Как поставить (с компьютера):
1. studio.youtube.com → слева «Настройка канала» → вкладка «Брендинг».
2. «Фото профиля» → «Загрузить» → `аватар_800x800.png` → рамку не двигать → «Готово».
3. «Баннер» → «Загрузить» → `RU_баннер_2560x1440.jpg`. YouTube покажет три рамки (телевизор, компьютер, телефон) —
   надпись уже стоит в центре, рамки не двигать → «Готово».
4. Справа вверху «Опубликовать».

Для английского канала — то же самое с `EN_banner_2560x1440.jpg`.
Требования YouTube: баннер не меньше 2048×1152, до 6 МБ; аватар от 98×98, до 4 МБ — файлы им соответствуют.
Исходник оформления: `render/youtube_brand.py` (стиль `storm_clubs`, языки `--lang ru|en`).
