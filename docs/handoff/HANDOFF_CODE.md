## 2. Правила работы (обязательно)

1. **Перед загрузкой кода в таблицу** — скачать живой код (`clasp clone <scriptId>` в пустую папку) и сравнить с последней загруженной версией из git. Отличается — значит кто-то правил руками или из другого чата: сначала слить изменения, потом загружать. 30.09 скрипт КХЛ уже однажды затёрли старой копией — все доработки пропали, пришлось восстанавливать.
2. Загрузка: `cd apps-script/project && clasp push --force` (или `apps-script/nhl`), потом снова `clasp clone` и сравнить — живой код должен совпасть с репозиторием.
3. В редакторе Apps Script руками код не править. Если правили — сначала забрать изменения в репозиторий.
4. Публичные тексты: **не упоминать аналитическую таблицу**, писать от лица автора, **без подписи «Джарвис»**, **без эмодзи** в подписях к постерам.
5. Не тратить лимиты пользователя (Gemini и т. п.) на проверки — проверять на макетах (node + подменённые сервисы).
6. Не править `render/poster.py` (старый набор карточек) — только надстройки рядом.

## 3. Что сделано (и где в коде)

### Автоматика и надёжность (КХЛ)
- Журнал автоматики: лист «Журнал_автоматики», `autoMark_` / `autoStart_` / `autoWatchdog_`, оповещения админу о сбоях.
- Утреннее обновление частями (лимит Google 6 минут): `runAfterGameDay_` → `agdRun_` / `agdSteps_` / `agdFinish_`, продолжение `runAfterGameDayContinue_`.
- LIVE-пост «Матчи дня · результаты» в канале — только счёт, без отметок прогнозов (`liveText_(…, clean=true)`), копия в привязанную группу (`TG_GROUP`, команды `/group`, `/group_off`).
- Команды бота в личке: `/today`, `/team`, `/table`.
- Статистика КХЛ пишется числами, Data!K:N заполняется.

### Видео экспертов (обе таблицы, меню «🎬 … · Видео»)
- «🎬 Вставить видео» → ссылка → сразу разбор в Gemini (`videoInsert_`, `videoAnalyzeAll_`).
- Gemini определяет лигу ролика: ролик про другую лигу останавливается после 2 кусков со статусом «вставьте в таблицу …».
- Счётчики пустых кусков живут между запусками, страховочный перезапуск через 8 минут.
- Расклад экспертов сам идёт в стартовый рейтинг (доля 1/3), новости (травмы, вратари, форма) → поправки на 7 дней до ±15 очков с причиной «видео экспертов» (`preseasonAutoApply_`, `videoTweaksSync_`, `videoApplyRun_`). «Вернуть прежний стартовый рейтинг» выключает автоучёт (`VIDEO_AUTO_OFF`).
- Ссылки, спрятанные под подписью ячейки, распознаются.

### «Мои поправки» (обе таблицы)
- В рейтинге справа на листе «Мои поправки» колонка «Моя поправка ✏️» — поле ввода. Вписал число → меню «✍️ Поправки» → «✅ Принять поправки» (`tweaksAcceptNow_`, `tweaksFromRanking_`): пересчёт шансов, «Лучший прогноз», «Прогнозы — кратко», «Коэффициенты», игра, табло, рейтинг. Причина таких строк — «вручную (рейтинг)», видео их не перебивает.

### НХЛ
- Время матчей — по официальному расписанию НХЛ, не по Pinnacle (Pinnacle ставит +7 минут: 02:37 вместо 02:30) — `nhlFixStartTimes_` в `updateMarketOdds_`.
- Кнопки «🖼 Готовый постер → мне / → группа»: картинка и подпись берутся с Google Диска из файла `jarvis_poster_nhl.json` ({file, caption, title}) — для разовых постеров, код менять не нужно.

### Постеры — автоматически в каналы (GitHub Actions рисует, таблицы заказывают)
Таблица шлёт `repository_dispatch` в GitHub (свойство скрипта `GITHUB_TOKEN`, fine-grained, Contents: Read and write), задание рисует набором `render/` и публикует ботом (секрет репозитория `TG_BOT_TOKEN`).

| Пост | Когда (МСК) | Кто заказывает | Куда |
|---|---|---|---|
| «Матчи дня» (формат «Колонки») | КХЛ 09:00, НХЛ 18:00 (проверка в частых запусках: LIVE КХЛ каждые 5 мин, разведчик НХЛ каждые 15; `MATCHI_HOUR_MSK`) | каждая таблица | КХЛ: канал + группа; НХЛ: канал |
| «Итоги дня» КХЛ (формат «Ячейки», больше 5 матчей — альбом, как «Матчи дня») | 00:00 МСК после игрового дня (`itogiMidnightKhl_`) | КХЛ | канал + группа |
| «Итоги дня» НХЛ (то же) | сразу как доиграна ночь (проверка каждые 15 мин в `scoutReportAuto_` → `nhlNightDoneAuto_`, окно 03:00–13:00) | НХЛ | канал |
| «Игроки дня» (текст): КХЛ — топ-7 по очкам + лучшие вратари; НХЛ — «Наши» (по протоколам с сайта НХЛ, `nhlOursFromApi_`) | сразу следом за итогами НХЛ (то же задание GitHub, поля `after_text` / `after_chats`); если не ушёл — в 10:00 (`playersDayAuto_`) | НХЛ | канал НХЛ + канал и группа КХЛ |

- Общий файл на Google Диске `jarvis_itogi_khl.json` (`sharedRead_` / `sharedPatch_`): после утреннего обновления КХЛ (≈02:00 МСК) — лучшие игроки (`khlStatsShare_` в `agdFinish_`) для поста «Игроки дня».
- Страховки: итоги НХЛ не вышли после ночи → в 10:00 НХЛ публикует постер (`itogiAutoNhl_`), а если и его нельзя заказать — старый текст «итоги ночи». Задание не смогло нарисовать картинку → публикует подпись текстом. Общий пост КХЛ + НХЛ (`itogi2`, `itogiBothDispatch_`) автоматикой больше не используется.
- «ОВЕРТАЙМ» / «БУЛЛИТЫ» различаются: КХЛ — со страницы матча sports.ru, НХЛ — из API НХЛ.
- Кнопки «📣 … · ТГ группа»: «🖼 Постер «Матчи дня» → мне / → группа», «🖼 Постер «Итоги дня» → мне / → группа» («→ группа» — туда же, куда автоматика, со вопросом-подтверждением и предупреждением, если за этот день постер уже выходил), «📊 Пост «Игроки дня» → мне», «🔑 Подключить GitHub для постеров».

## 4. Решения — к ним НЕ возвращаемся

- Анимированные (премиум) эмодзи бот в канал ставить не может → в подписях к постерам эмодзи нет вообще.
- Итоги лиг публикуются **отдельно** (решение 02.10, заменило общий пост КХЛ + НХЛ): КХЛ в 00:00 МСК, НХЛ сразу после ночи; оформление как у «Матчей дня» (портрет, альбом, плашки на одном уровне). Текстовый пост НХЛ «итоги ночи» заменён постером.
- «Наши» (россияне НХЛ) — не в подписи к итогам, а в отдельном посте «Игроки дня» в 10:00 вместе с лучшими игроками КХЛ.
- Публикация постеров в каналы — автоматическая (решение пользователя). Кнопки «→ мне» — только для проверки.
- Время «Матчей дня»: КХЛ 09:00, НХЛ 18:00 МСК — два отдельных поста.
- «Игроки дня» — сразу следом за итогами НХЛ, не в 10:00 (10:00 — только запасной вариант).
- Время матчей НХЛ — только официальное (:00 / :30).
- Ролик «Слиппери Айс» (Майков, Шубин) — про НХЛ, в таблице КХЛ не нужен.
- Повторный вход clasp с правом чтения Диска не нужен: данные таблиц читаются через коннектор Google Drive (экспорт xlsx).
- Старый Python-бот — в архиве, не восстанавливаем.

## 5. Что осталось / на заметку

- Первый полный общий пост (два баннера) — с итогов 1 октября. За ночь 30.09→01.10 он только с НХЛ (КХЛ 30.09 вышли отдельно по старой схеме). Проверить результат: GitHub → Actions → «Постеры «Итоги дня» и «Матчи дня»».
- Ключ `GITHUB_TOKEN` имеет срок действия — когда истечёт, постеры перестанут заказываться: создать новый (github.com/settings/personal-access-tokens/new, только этот репозиторий, Contents: Read and write) и вставить кнопкой «🔑 Подключить GitHub для постеров» в обеих таблицах.
- Не сделано: надпись «…ПО ДАННЫМ АНАЛИТИЧЕСКОЙ ТАБЛИЦЫ» внизу старой карточки одного матча КХЛ (`render/poster.py`) — заменить надстройкой, не трогая poster.py.
- Не сделано: убрать из меню КХЛ две тестовые кнопки «🖼 Тест «Итоги дня» с картинкой» (их заменил автопостер).
- Не сделано: копии постов НХЛ в группу (у КХЛ есть).
- В НХЛ можно нажать «🎬 НХЛ · Видео» → «🔄 Учесть видео в прогнозах сейчас», чтобы расклад по уже разобранным роликам ушёл в рейтинг сразу.

## 6. Как проверять, ничего не тратя

- Синтаксис: `node -e "new Function(require('fs').readFileSync('apps-script/nhl/Код.js','utf8'))"`.
- Логику — макетом: загрузить файл в `vm`, подменить `SpreadsheetApp`, `PropertiesService`, `UrlFetchApp`, `ScriptApp`, `DriveApp` простыми объектами (даты создавать внутри контекста vm, иначе `instanceof Date` не сработает).
- Постеры локально: `python3 render/itogi_job.py payload.json` (без `TG_BOT_TOKEN` только рисует).
