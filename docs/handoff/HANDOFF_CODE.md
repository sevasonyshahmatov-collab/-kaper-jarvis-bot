## 2. Правила работы (обязательно)

1. **Перед загрузкой кода в таблицу** — скачать живой код (`clasp clone <scriptId>` в пустую папку) и сравнить с последней загруженной версией из git. Отличается — значит кто-то правил руками или из другого чата: сначала слить изменения, потом загружать. 30.09 скрипт КХЛ уже однажды затёрли старой копией — все доработки пропали, пришлось восстанавливать.
2. Загрузка: `cd apps-script/project && clasp push --force` (или `apps-script/nhl`), потом снова `clasp clone` и сравнить — живой код должен совпасть с репозиторием.
3. В редакторе Apps Script руками код не править. Если правили — сначала забрать изменения в репозиторий.
4. Публичные тексты: **не упоминать аналитическую таблицу**, писать от лица автора, **без подписи «Джарвис»**, **без эмодзи** в подписях к постерам.
5. Не тратить лимиты пользователя (Gemini и т. п.) на проверки — проверять на макетах (node + подменённые сервисы).
6. Не править `render/poster.py` (старый набор карточек) — только надстройки рядом.

- Синтаксис: `node -e "new Function(require('fs').readFileSync('apps-script/nhl/Код.js','utf8'))"`.

- Макет Google Таблиц: `tools/gas_mock/gas_mock.js` — исполняет код таблиц в node (значения, оформление, строгие границы листа, «2:1» → дата в нетекстовой ячейке),
