Правила для всех промтов: без логотипов клубов и лиг, без формы реальных команд, без лиц реальных людей, без текста и цифр
в кадре (титры кладёт наш код). В Instagram — пометка «Создано ИИ». Расход токенов — оценка: реальную цену показывает
кнопка генерации, сверять на первой генерации каждого типа.
