## 2. Решения владельца 31.10 (действуют для всех)

**Купоны:**
- Главное — шанс зайти, а не кэф. Каждое событие — самый вероятный исход по модели, кэф **1,20–1,65**, общий кэф — ориентир **1,80–2,00** (не жёстко).
- В купоне **не больше одной форы** (иначе модель набирает одни «+1,5»); остальное — инд. тоталы, тотал, победа. Матчи между купонами не повторять.
- **Пост: только шапка, события (матч, время МСК, ставка, кэф) и «Общий кэф». Без процентов, без «почему», без «не зайдёт, если…».** Баннер — гифка (картинка — запасная) + сторис 1080×1920.
- Кнопка «Опубликовать» под купоном (`ДДММ-eN`) → сразу в канал **и в Instagram** (лента + сторис) через `itogi.yml` (`team/picks/express_ig.py`; PR #135). Расчёт модели — только в `team/picks/EXPRESS_LOG.md`, не в посте.
- Скрипты: `team/picks/express.py` → `express_post.py` → `express_render.py` → `express_send.py`; баннер `render/express_card.py`.

**Прогнозы (все):**
- **В постах никогда не писать проценты/уверенность** («Уверенность модели ниже 60 %…» — убрано из README и `jarvis-picks`). Ниже порога — сказать только в обзоре владельцу.
- Источник (betzona и т. п.) не указывать, тексты свои, факты наши, без букмекеров.
- betzona: кэф от 1,6 (1,40–1,59 — только если модель заметно выше рынка). Открытый вопрос владельцу: брать только матчи, где модель выше рынка на 2–3 п. п.?

**Итоги:**
- «Итог матча» — **только по ставкам, опубликованным в канал** (по `team/INBOX.md`), не по черновикам. **По футболу тоже** — с футбольным баннером (PR #136: `pmFootDispatch_` после финала по ESPN).
- Один итог на прогноз: `team/postmatch/run.py` сверяет `.pm_recent/done.json` и `team/postmatch/sent_pm.json`; повтор только с `"force": 1`.
- Нейросети недоступны (Gemini 503, у Claude API нет баланса) → итог по шаблону из фактов, а не «пост не готов».
- **Утренние «Итоги прогнозов» — двумя постами:** хоккей `ДДММ-r1` и футбол `ДДММ-f1` (`team/daily/foot_recap.py`); купоны в итоги не входят. Первый раз — утро 01.11, проверить, что пришли оба.
