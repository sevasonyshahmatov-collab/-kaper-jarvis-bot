## Как работать с владельцем

- Владелец в Красноярске (МСК+4). Ключи/токены в чат не просить — только в секреты GitHub
  (Settings → Secrets and variables → Actions).
- Правила экономии токенов — `team/RULES.md`, раздел «Экономия токенов»: тяжёлое — в Actions, логи по меткам, не следить
  за запусками опросом, ответы — итог и что нужно от владельца.
- Список задач — `team/BACKLOG.md` (№12–16 — соцсети и смежное).

## Что уже работает: конвейер шортсов (YouTube + Telegram)
Код — `team/reels_daily/` (README там), задание — `.github/workflows/reels-daily.yml`. Без Claude, лимиты не тратит.
- **Расписание:** НХЛ — 02:00 МСК (06:00 Красноярск), матчи ближайшей ночи; КХЛ — 02:30 МСК (06:30 Красноярск), матчи
  этого дня. Владелец: ролики выходят заранее, за 12–15 ч до матча.
- **Прогноз** — правило владельца из «Что заходит» (`team/picks/calc.py`): самое вероятное событие с кэфом 1,6–2,3
  (равный матч — ближе к 1,6–1,7, аутсайдер против сильного — 1,8–2,0). Линия на момент запуска.
- **Один матч — один ролик**; все утверждённые шаблоны строго по очереди, без привязки к виду ставки (20 вариантов:
  9 шаблонов 14.10, 5 вариантов с треками 16–17.10, 6 шаблонов 12.10). Не в очереди: «Купон», «Топ-3» (несколько матчей
  в ролике), «Чат» (нет трека refl). Шаблоны — `team/reels_selected/README.md`, параметры — `TEMPLATES` в `make.py`.
- **Ролик:** 1080×1920, 30 к/с, H.264 до 9 Мбит/с, AAC 192k, ~23 с, ~27 МБ; со звуком и `_clean` (без музыки).
- **Telegram:** владельцу (создатель канала @jarvibet) — ролик с подписью (ссылка YouTube + название + описание +
  хэштеги) и следом версия без музыки. Плюс утренний список матчей с прогнозами.
- **YouTube** (`team/reels_daily/youtube.py`): загрузка сразу «для всех», категория «Спорт», тексты — `yt_texts.py`
  (название «Команда — Команда: прогноз на матч ДД.ММ.ГГГГ», описание с матчем, временем МСК, прогнозом и кэфом,
  кликабельная `https://t.me/jarvibet`, хэштеги #хоккей #КХЛ/#НХЛ #прогноз #Клуб #Клуб).
  Секреты: `YT_CLIENT_ID`, `YT_CLIENT_SECRET`, `YT_REFRESH_TOKEN` (проект Google Cloud «JARVIS YouTube»).
- **Ручной запуск:** Actions → «Шортсы — конвейер» → Run workflow; или из ветки `claude/**` записать в
  `team/reels_daily/RUN` «лига день [сколько] [Клуб,Клуб]» и запушить (осторожно: любой пуш, меняющий RUN, запускает
  конвейер). Ролики — артефакт запуска на 2 дня.
- **Треки** — зашифрованы в ветке `claude/team-dev-tracks-v2` (секрет `TRACKS_KEY`). Новые треки без ключа в чате:
  `tools/tracks_inbox/pack.sh <папка с mp3>` → коммит `tools/tracks_inbox/box/` в ветку `claude/**` →
  `tracks-intake.yml` шифрует в ветку треков; потом ящик из ветки убрать.

## YouTube — ограничения (важно)
- Приложение Google — **«In production»** (проверено владельцем 23.10, проект «JARVIS YouTube», jarvis-youtube-511907): ключ, выданный
  после перевода, не истекает; ключ, выданный ещё в «Testing», живёт 7 дней с выдачи. Раньше было «Testing»: `YT_REFRESH_TOKEN` живёт
  **7 дней**. Истёк — в подписи Telegram «обновите YT_REFRESH_TOKEN»: OAuth Playground (свой Client ID/secret,
  Access type Offline, scope `https://www.googleapis.com/auth/youtube.upload`) → новый refresh token в секрет.
- **Квота ~6 загрузок в сутки**; сутки YouTube — с 10:00 МСК. Сверх лимита — в подписи «загрузите вручную» (ручная
  загрузка в Studio квоту не тратит). Днём через API ничего не грузить — иначе утренний запуск останется без квоты.
- Снимает оба ограничения заявка **YouTube API Services Audit** (BACKLOG №15) — помочь заполнить.
- Посты во вкладке «Сообщество» через API нельзя — только вручную.
- Канал: «JARVIS BET | Прогнозы на хоккей НХЛ и КХЛ», телефон подтверждён. Оформление — `docs/channel/youtube/`,
  решения по YouTube — `team/YOUTUBE.md`.
