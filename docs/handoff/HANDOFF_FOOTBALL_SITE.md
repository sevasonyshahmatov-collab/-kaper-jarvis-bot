## 2. Цифры, которые можно показывать на сайте (все — из `football_bt.md`, проверка вслепую на сезоне 2025/26)
Правило: на сайте только проверенные цифры с источником, без «верняков», БК, промокодов (`team/RULES.md`, voice.md).
- История: 6 лиг × 2021/22–2026/27 ≈ **11 000 матчей**; еврокубки 2021–2027 — **2 400 матчей**; ещё 14 лиг соперников.
- Модель: сила атаки и обороны (Пуассон, поправка Дикси — Коулза), смесь голов и xG; новичок лиги стартует слабее.
- **Честный вывод:** одна модель рынок не бьёт (обещала 63,7 % → зашло 56,5 %). Смесь «модель + линия Pinnacle» обещает
  честно (по корзинам 55–90 % расхождение 1–2 п. п.).
- Порог «ВЫБОР» **от 60 %, кэф от 1,6**: 284 ставки, обещано 62,5 % → **зашло 60,9 %**, ROI +0,9 % по закрытию.
  Почему 60 %: ниже — обещание не сходится, выше 62 % — ставок мало и они хуже (таблица порогов в `football_bt.md`).
- По рынкам от 60 %: **1Х2** 60 ставок, 63,2 → 68,3 % (+14,3 %); **тотал 2,5** 91 ставка, 62,1 → 64,8 % (+7,1 %).
  Не берём: «не проиграет» (−8,6 п. п.), тотал 3,5, «обе забьют».
- По лигам от 60 %: Ла Лига 62,7 → 71,1 %, Серия А 62,6 → 68,4 %, Бундеслига 63,2 → 60,6 %, АПЛ 61,8 → 58,5 %,
  Лига 1 62,3 → 56,2 %, **Португалия 62,5 → 50,0 % — исключена**. Выборки 35–65 ставок, погрешность ±13 п. п. —
  на сайте подписывать «предварительно».
- Еврокубки: своя шкала силы лиг (таблица «сила лиг к АПЛ» в `football_bt.md`) — logloss 0,955 против 1,055 без неё.
  Кэфов еврокубков в истории нет → ROI не считали. В пробе ЛЧ и ЛЕ, ЛК позже.
- Келли (¼) хуже ровной ставки (от 60 %: −3,1 % против +0,7 %) → суммы и «банк» не обещаем.
- «Разница классов»: фаворит против слабой обороны делает **меньше**, чем ждёт модель (голы −11,6 %, угловые −8,2 %) —
  хороший сюжет для раздела «как думает модель».
- Широкая роспись (run 597): вероятности угловых, ударов в створ, таймов, инд. тоталов честные (±1 п. п.); «обе забьют»
  переобещает. **Кэфов на эти рынки в истории бесплатно нет** (проверено 30.10: SofaScore 403, BetBoom 401,
  BetExplorer/OddsPortal — только скриптом страницы, обход защиты не делаем) → **решение владельца: копим свою линию
  Pinnacle** (`.lines/football_wide/<день>.jsonl`), первая сверка ~13.11. До неё «ВЫБОР» по этим рынкам нет.

   результаты футбольных прогнозов (из `FOOT_RESULTS.md`, когда наберутся), карточки команд («наносит / допускает»).
   Заходимость футбола на сайте — только после 2 недель пробы и только реальная (ТЗ этап 3).
