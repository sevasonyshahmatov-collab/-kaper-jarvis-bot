Этот файл — всё важное о постерах и баннерах. Дай его новому чату целиком.

## 1. Где всё лежит

- Репозиторий `sevasonyshahmatov-collab/-kaper-jarvis-bot`, папка **`render/`** — весь набор: шрифты (`fonts/`), эмблемы КХЛ и всех 32 клубов НХЛ (`emblems/`), знаки лиг (`league/khl.png`, `nhl.png`, `khl_dark.png`, `nhl_dark.png`), модули.
- Каталог всех форматов с описанием — **`render/STYLES.md`**.
- Подключение НХЛ: `import nhl; nhl.register()` — после этого клубы НХЛ работают в любом рендере; названия понимаются как угодно («Рейнджерс», «NYR», …).
- Не править `render/poster.py` (старый набор) — только новые модули рядом.
- Python 3.11, Pillow, numpy. Рисование с запасом S=2, ширина 1080.

## 2. Утверждённые шаблоны (используются в автоматике)

| Пост | Модуль и вызов | Как выглядит |
|---|---|---|
| **«Итоги дня»** (КХЛ и НХЛ) | `results_ice2.render(items, path, variant=10, league='KHL'/'NHL', date_title='среда, 30 сентября')` | «Ячейки»: светлый лёд, иней сверху под заголовком, логотипы во всю ячейку без названий, проигравший — серым силуэтом, по центру тёмное табло: цифра победителя золотая со свечением, проигравшего серая; полоска цвета клуба у табло; пометки «ОВЕРТАЙМ» / «БУЛЛИТЫ» |

## 3. Правила оформления (утверждены)

- Фон светлый «лёд», иней только сверху под заголовком «ИТОГИ ДНЯ» / «МАТЧИ ДНЯ», зернистость фона сохранять.
- Шрифты «Боков»: Oswald — заголовок и названия, Unbounded — цифры и @jarvibet, Manrope — дата и подписи.
- Шапка `JARVIS | KXL` / `JARVIS | NHL`, внизу `@jarvibet`.
- Никаких корон и галочек. В итогах — без названий команд (только логотипы).
- Время матчей НХЛ — официальное (:00 / :30), не из линии Pinnacle (там +7 минут).
- Нигде не упоминать аналитическую таблицу; без подписи «Джарвис».
- **Подписи к постам — без эмодзи** (премиум-эмодзи бот в канал ставить не может, обычные решили не ставить).

### Форматы подписей
«Матчи дня»:
```
02:30 | Филадельфия — Питтсбург
02:30 | Торонто — Айлендерс
05:00 | Колорадо — Лос-Анджелес

Время московское.
```
Общий пост итогов:
```
Итоги игрового дня · среда, 30 сентября

КХЛ
Сочи — Лада 3:2 Б

НХЛ
Каролина — Флорида 0:1 ОТ
```
«Игроки дня» (текст, сразу после поста с итогами): «КХЛ · лучшие игроки» (топ-7 по очкам, вратари) и «НХЛ · наши».

## 4. Автоматика (что уже работает само)

`render/itogi_job.py` запускается GitHub Actions по событию от таблиц и публикует в каналы:
- `matchi` → «Матчи дня» (КХЛ 09:00, НХЛ 18:00 МСК);
- `itogi2` → общий пост «Итоги игрового дня» (два баннера) сразу после последней игры НХЛ, следом — текст «Игроки дня»;
- `itogi` → отдельный постер итогов одной лиги (запасной вариант).

Меняешь внешний вид — правь `results_ice2.py` (variant 10) / `preview_ice.py` (columns), проверь локально и слей в `main`: автоматика сразу начнёт рисовать новое.

Проверка локально, без отправки: `python3 render/itogi_job.py payload.json` — картинка сохранится рядом.
Пример `payload.json`:
```json
{"kind":"itogi2","date_title":"среда, 30 сентября","leagues":[
 {"league":"KHL","items":[{"home":"Сочи","away":"Лада","sh":3,"sa":2,"mark":"Б"}]},
 {"league":"NHL","items":[{"home":"Каролина","away":"Флорида","sh":0,"sa":1,"mark":"ОТ"}]}]}
```
