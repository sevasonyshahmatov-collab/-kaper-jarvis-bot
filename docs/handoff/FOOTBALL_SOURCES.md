  API-Football **не нужен**; пригодится только как запасной, если Pinnacle закроет гостевой доступ.
- История и бэктест: football-data.co.uk (закрытие Pinnacle до 2025/26 включительно) + xG Understat для топ-5
  (Португалия — «xG по ударам») + ESPN для еврокубков.

  еврокубков прошлых лет, `team/picks/football_bt.py`).
