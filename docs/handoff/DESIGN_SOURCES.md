## 1. Скиллы-«дизайн-студия» для агента (сайт, карточки, карусели)
Порядок работы, как в ролике, — по ролям:

| Роль | Скилл | Лицензия | У нас |
|---|---|---|---|
| Арт-директор: сначала стиль (палитра, шрифты, идея), потом код | `frontend-design` — официальный скилл Anthropic, github.com/anthropics/skills | Apache-2.0 | есть (28.10) |
| Перфекционист: находит кривые отступы, случайные цвета и чинит | `impeccable` | Apache-2.0 | есть |
| Вкус: «ползунки» смелости, уводит от шаблонного «сгенерированного» вида | `taste-skill` v2 (design-taste-frontend), github.com/Leonxlnx/taste-skill | MIT | есть (28.10) |
| Аниматор: плавные выезды, раскрытие карточек «с пружиной» | `emil-design-eng` (Эмиль Ковальски) | MIT | есть |
| Глаза: агент снимает скриншот и сам видит косяки | Playwright | Apache-2.0 | есть (`shot.js`) |

- taste-skill v2: скрипты `draw.mjs` (выдаёт 3 направления дизайна из 20, собранных по 247 сайтам Awwwards / One Page
  Love), `inspect.mjs` (проверка в браузере), снимки на трёх ширинах. Нужны Node 22+ и Chromium — в облаке есть.
  Есть отдельный режим для «экранов приложения» (`--app`) — подходит для вкладок таблицы и статистики на сайте.
- Правило: после любой правки сайта — скриншоты на 3 ширинах (телефон / планшет / ПК) и самопроверка до PR.
- Фирменный стиль не меняется: золото на тёмном. Скиллы — для качества внутри этого стиля, а не для смены стиля.

## 3. Voicebox — озвучка роликов своим голосом
github.com/jamiepine/voicebox, MIT, ~17,5 тыс. звёзд. Локальное приложение (macOS / Windows / Linux): клон голоса по
образцу ~20 секунд, 7 моделей, 23 языка (есть русский), диктовка, MCP-сервер для агентов. Без аккаунта и подписки.
- Применение: закадровый голос в Reels / Shorts **голосом владельца** (только своим — чужие голоса не клонировать).
- Работает на компьютере владельца, не в облаке и не в Actions (нужна мощная машина). Решение — за владельцем.

## 4. Приёмы из самих роликов — для наших Reels и каруселей
1. Субтитры по словам, одно слово выделено плашкой (у нас — золотом).
2. Нумерация «01 / 05» в списочных роликах и каруселях: зритель видит, сколько осталось, и досматривает.
3. Первая фраза — проблема зрителя («все сайты бежевые»), а не название продукта.
4. Призыв одним словом **в комментариях** («напиши UI», «напиши VOICE» → ссылка в ответ). Комментарии поднимают охват
   сильнее, чем директ. Для нас: «напиши ТАБЛИЦА в комментариях» + автоответ в директ (связано с вопросом владельца,
   кто отвечает на «ТАБЛИЦА»).
5. Постоянный персонаж / талисман в кадре — узнаваемость серии (идея для JARVIS).
6. Макеты интерфейса как картинка (поле комментария, которое «печатается», окно приложения) — вместо стоковых фото.
7. Финальный экран «Подпишись»: аватар, ник, кнопка меняется на «Вы подписаны».
