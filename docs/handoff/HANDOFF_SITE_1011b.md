## Как пересобирать страницы матчей
Обычная сборка `python3 team/site/v3a/seo/build_seo.py` трогает только окно 3 дня. Чтобы обновить все существующие папки матчей —
разовый скрипт: `BM.PAST_DAYS=30`, после `collect()` удалить из `BM.MATCHES` матчи старше 3 дней, чьих папок нет, затем `B.main()`;
после этого `git checkout -- data/matchlinks.js sitemap.xml` (иначе в них попадут старые страницы).
