# Сайт v2 — «камера-путешествие» (промпт владельца 30.10 + доработка)

Суть владельца (не терять): фон — живая камера-дрон. Футбол: огромный открытый стадион вечером (в духе новых стадионов
Саудовской Аравии, вымышленный), дрон кружит → при прокрутке снижается, влетает через вход в лобби с флагами и
гербами клубов → летает по локациям стадиона → тоннель → вылет на поле, подъём вправо → в конце снова воздух, ниже и под
другим углом. Всё время на поле идёт матч. Внизу кнопка «ПРОГНОЗЫ НА ХОККЕЙ» → быстрый поворот камеры на 360° →
хоккейная арена с матчем → пролёт вдоль льда между игроками → тоннель → раздевалка → … Обратно — «ПРОГНОЗЫ ПО ФУТБОЛУ»,
тот же поворот. Плашки — объёмные, как на лендинге, не плоские.

## 1. Как это сделать технически (что меняем в подаче, а не в сути)
1. **Одно длинное видео нейросеть не снимет** (Higgsfield/Kling/Veo — 5–10 с на ролик). Путь камеры режем на отрезки,
   у соседних **последний кадр одного = первый кадр следующего** (режим start/end frame). Склейка без шва.
2. **Прокрутка двигает видео** (scrub): кадр ролика привязан к положению прокрутки — листаешь вниз, камера летит
   вперёд, вверх — назад. Видео кодируем «каждый кадр ключевой», на телефоне — облегчённое (720p, меньше кадров).
3. **Ожидание без прокрутки** — короткая петля (кружение 10–15 с, замедленное, бесшовное). Полный облёт за 1,5 мин
   = петля 15 с на скорости ×0,2–0,3 — тот же эффект, в разы дешевле.
4. **Матч на поле**: 2 минуты связной реалистичной игры нейросеть не даст; с высоты дрона игроки мелкие — хватает
   петли 8–10 с с игрой вдали. Кадры настоящих трансляций нельзя (права).
5. **Гербы в лобби — кодом поверх видео, не в генерации**: нейросети искажают и часто отказываются рисовать гербы.
   Генерируем лобби с пустыми флагами/баннерами цветов клубов, а настоящие эмблемы (у нас 180 клубов,
   `render/emblems/`) вешаем 3D-слоями в разной глубине — они плывут с параллаксом, пока камера летит, и **нажимаются**
   (герб → страница клуба/лиги). Объём + интерактив + точные гербы.
6. **Поворот 360° между спортами** — короткий ролик «вихрь» (1 с) + размытие движения кодом и наплыв на вторую
   арену. Можно и без ролика: поворот и размытие кадра в коде (дешевле, проверим оба).
7. **Каждая остановка камеры = раздел сайта** (ниже). Текст и плашки — поверх, в «спокойной» части кадра.
8. Телефон и «меньше движения»: постеры + короткие петли, переход по разделам наплывом, без scrub.

## 1а. Референс F0 от владельца (30.10)
Ракурс — как на снимке Камп Ноу с вертолёта: камера наклонена ~40–45° вниз, высота ~150–200 м, стадион занимает
~85–90 % кадра (чаша видна целиком, края почти у рамки), поле — в центре-ниже, видна глубина ярусов трибун и козырёк
крыши с одной стороны; город, деревья, улицы и машины — только по краям. Стадион делаем вымышленным (без надписей на
трибунах, без логотипов на табло), но такой же близкий и «плотный» в кадре; время — вечер, чаша светится изнутри.

## 1б. Референс F2 «подтрибунное помещение» (владелец 30.10, `team/site_v2_refs/F2_concourse.webp`)
Высокое подтрибунное пространство (атриум на 4–5 этажей): изогнутая стена-чаша слева с цветными рёбрами (красный/синий),
голый бетон, косые балки трибуны над головой, справа ярусы балконов с перилами на мощных колоннах, лестницы-переходы
вглубь, тёплый закатный свет полосами между колоннами + холодная синяя подсветка по кромке, пол тёплый матовый, люди
мелкие. Камера — на уровне ~2–3 м, летит по центру прохода вглубь. Сюда — флаги и баннеры клубов на разной высоте
(свисают с балок и балконов), гербы — 3D-слоями кодом. Людей в генерации — мало/силуэты вдали (или без людей).

## 1в. Референс «подтрибунное помещение 2» (владелец 30.10, фото клубного магазина-атриума)
Круглый атриум в 2–3 уровня: сверху кольцо с синей неоновой подсветкой по кромке, под потолком — белые изогнутые
ленты-скульптуры и точечные светильники; по кругу — ряд игровых футболок с номерами на манекенах; ниже — изогнутый
сплошной LED-экран по всей окружности перил; внизу — зал с витринами формы; чёрные перила, лестница вниз. Камера —
на верхнем уровне у перил, смотрит через атриум.
У нас: **футболки разных клубов** (цвета 19 клубов из списка владельца, без названий спонсоров) вместо одного клуба;
**изогнутый LED-экран = место для наших данных** — на него кодом выводим матчи дня / «обещали–зашло» (экран в кадре
пустой тёмно-синий, контент — наш слой с перспективой). Неон кольца — циан/зелень раздела.
Связка: F2 лобби (1б) → F2b атриум-«зал клубов» (1в) → F3 аналитика.

## 4. Общая главная (`/`)
Развилка без длинного видео: два «портала» рядом — справа петля F0 (стадион), слева H0 (арена); наведение/касание
раскрывает портал на весь экран → вход в сценарий спорта. Ниже — объёмные плашки (наклон к пальцу, глубина слоёв,
мягкие тени, перспектива): прогноз дня по обоим спортам, честные итоги, модель, Telegram. Стиль — ночь, золото,
циан (лёд) / зелень (газон), как в макете `team/site/v2/`.
