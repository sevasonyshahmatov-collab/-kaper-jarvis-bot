# JARVIS — справка о проекте для чата «Соцсети» (Instagram и YouTube)

## 1. Что за проект
- **JARVIS** — прогнозы на хоккей: **КХЛ** (каждый игровой день) и **НХЛ** (ночные матчи по Москве).
- Главная площадка — Telegram-канал **@jarvibet** (`https://t.me/jarvibet`): посты-прогнозы на каждый матч, итоги, баннеры.
  Всё остальное (YouTube, Instagram, ВКонтакте) ведёт людей туда.
- Владелец — один человек, живёт в Красноярске (МСК+4). Время матчей в материалах — московское.
- Прогнозы считает собственная модель («Что заходит»): вероятность события по форме команд + коэффициенты букмекеров.
  Правило отбора для роликов: самое вероятное событие с кэфом **1,6–2,3** (равный матч — ближе к 1,6–1,7,
  аутсайдер против сильного — 1,8–2,0).
- Техника: репозиторий GitHub `sevasonyshahmatov-collab/-kaper-jarvis-bot` (ветка `main`). Всё тяжёлое — рендер, данные,
  загрузки — делает GitHub Actions по расписанию, без участия ИИ. Подробности по соцсетям — `docs/handoff/SOCIAL.md`.

## 2. Бренд и тексты
- Название: **JARVIS**; YouTube-канал «JARVIS BET | Прогнозы на хоккей НХЛ и КХЛ»; везде подпись `@jarvibet`.
- Пишем от лица автора, по-русски, просто. Без подписи «Джарвис».
- **Нельзя:** «ставь», гарантии и обещания выигрыша, реклама букмекеров, промокоды, «мнение автора» как оправдание,
  упоминание аналитической таблицы. Прогноз — мнение, не совет.
- Цифры — только проверенные (официальные сайты лиг, приложения, крупные СМИ). Нет источника — нет цифры.
- Падежи клубов: «победа Бостона», «Ак Барса», «Сибири», «Локомотива».
- Честность: итоги показываем и зашедшие, и нет.

## 3. Что уже готово и работает само
**Конвейер шортсов** (каждый день, без ИИ):
- **06:00 по Красноярску** — ролики на все матчи НХЛ ближайшей ночи; **06:30** — на все матчи КХЛ этого дня.
  Цель владельца: публиковать за 12–15 ч до матча, чтобы люди успели посмотреть.
- **Один матч — один ролик.** 20 утверждённых визуальных шаблонов идут строго по очереди (трейлер кино, графика
  трансляции, приборная панель, граффити, ювелирная витрина, кинетическая типографика, скачки, радар, VHS, «tale of the
  tape», терминал ИИ, коллекционная карточка, представление составов и др.).
- Ролик: вертикальный 1080×1920, 30 к/с, ~23 с, под музыку владельца (свои треки). Сюжет: матч и линия П1·Х·П2 →
  форма команды 1 (последние 3 игры, очки, место) → команда 2 → **прогноз и кэф ровно на дроп трека** → плашка Telegram.
  Есть версия без музыки — на случай претензий к звуку.
- **YouTube:** каждый ролик загружается автоматически, сразу «для всех». Название «Команда — Команда: прогноз на матч
  ДД.ММ.ГГГГ», описание (матч, время МСК, прогноз и кэф, ссылка на Telegram), хэштеги #хоккей #КХЛ/#НХЛ #прогноз #Клуб #Клуб.
- **Telegram:** владелец получает каждый ролик с готовым текстом для загрузки вручную.

**YouTube — ограничения сейчас:**
- Около **6 автозагрузок в сутки** (сутки YouTube начинаются в 10:00 МСК); остальное владелец грузит вручную.
- Доступ Google в тестовом режиме — ключ обновлять раз в **7 дней**.
- Оба ограничения снимает заявка в Google (YouTube API Services Audit) — ещё не подана.
- Посты во вкладке «Сообщество» — только вручную (API YouTube их не публикует).

## 4. Задача нового чата
Владелец (22.10): **«Веди мой YouTube и Instagram — выкладывай посты, рилсы и истории сам».**

**Instagram — план (ждёт подключения):**
- **Рилсы** — те же ролики конвейера, автоматически.
- **Истории** — утром «Матчи дня» с прогнозами, днём ролик или итоги вчера.
- **Посты-карусели** — прогнозы дня и честные итоги, из баннеров, которые проект уже рисует (4К, утверждённые стили).
- Нужно от владельца (один раз, ~20 мин, по инструкции): Instagram → **профессиональный аккаунт** («Автор»/«Бизнес»),
  привязать **страницу Facebook**, создать приложение на developers.facebook.com, ключ с правом
  `instagram_content_publish` и ID аккаунта — в секреты GitHub (`IG_TOKEN`, `IG_USER_ID`). Ключ живёт 60 дней —
  продлевать автоматически.
- Оговорки: правила Meta о ставках (без «ставь», букмекеров, промокодов, без платного продвижения); Instagram может
  приглушить музыку; лимит — 50 публикаций через API в сутки.
- **Первый вопрос владельцу:** аккаунт уже профессиональный и привязан к странице Facebook?

**YouTube — что ещё можно:**
- Еженедельный отчёт по шортсам в Telegram (воскресенье): просмотры, досмотры, подписки по шаблонам — какие шаблоны
  оставить. Нужна галочка «статистика» в том же доступе Google.
- Заявка YouTube API Services Audit — снять лимит 6 загрузок и 7-дневный ключ.

**Потом:** группа ВКонтакте и VK Клипы (те же ролики), затем Дзен.

## 5. Как работать с владельцем
- Сначала план в 3–4 строки → работа после «да». Варианты — 2–3, не больше.
- Сообщения короткие, по-русски, без жаргона: что сделано, что получилось, что нужно от него.
- Ключи и пароли **в чат не просить** — только в секреты GitHub (Settings → Secrets and variables → Actions).
- Экономить токены: тяжёлое — в GitHub Actions, логи читать по меткам, не следить за запусками опросом
  (правила — `team/RULES.md`, «Экономия токенов»).
- Важные решения записывать в файлы репозитория (`team/BACKLOG.md`, `docs/handoff/`), а не только в чат.
