## 3. Как отправлять владельцу в Telegram

Из облака Telegram недоступен. Всё идёт через GitHub Actions:

1. Положить JSON-задание в `team/out/<YYYY-MM-DD>/<имя>.json`. Образцы: `team/out/2026-10-13/verdict_owner.json`, `verdict_fix_owner.json`. Формат:
   ```json
   {"day":"2026-10-13","make":["render/make_picks_1310.py"],
    "messages":[
      {"to":"owner","type":"text","text":"..."},
      {"to":"owner","type":"photo","files":["out/1310/pick_nhl_x.jpg"],"text":"подпись для канала","buttons":"post","pid":"1310-21"},
      {"to":"owner","type":"documents","files":["out/1310/pick_nhl_x.jpg"],"captions":["... · 4К"]}]}
   ```
   - `make` — скрипты, которые рисуют картинки прямо в Actions. Картинки в git не коммитим.
   - `buttons: post` даёт кнопки «Опубликовать / Поправить / Не надо»: бот копирует сообщение в канал.
   - `pid` должен быть уникальным. Команда занимает `ДДММ-1…9`, я брал `ДДММ-20+`.
2. Закоммитить и запушить.
3. Запустить workflow `itogi.yml` (workflow_dispatch) на этой ветке с input `payload` = `{"kind":"team","job":"team/out/<день>/<файл>.json"}`.
4. Через 1–2 минуты проверить, что run завершился со статусом success.

## 4. Послематчевые баннеры (главная повторяющаяся задача)

- Стиль «Вердикт»: `ice_more2.single(m, path, style='verdict', league='KHL'|'NHL')`, размер 3240×4050.
- Для НХЛ сначала `import nhl; nhl.register()`.
- Готовые скрипты, копировать как шаблон:
  - `render/make_picks_1310.py` — НХЛ, ночь на 13.10;
  - `render/make_pick_khl_1210.py` — КХЛ 12.10;
  - `render/make_picks_1210.py` — НХЛ, ночь на 12.10.
- Пример данных:
  ```python
  dict(home='Нью-Джерси', away='Оттава', sh=1, sa=4, mark='',   # mark '' | 'ОТ' | 'Б'
       pick=dict(text='2X + ТОТАЛ БОЛЬШЕ 4,5', odds=2.12, hit=True,  # odds=None, если кэфа нет
                 checks=[('ОТТАВА ВЫИГРАЛА 4:1 — 2X ЗАШЛА', True), ('5 ГОЛОВ — ТОТАЛ БОЛЬШЕ 4,5 ЗАШЁЛ', True)]))
  ```

## 5. Прогнозы для Betzona (сделано 12.10)

- Владелец публикует прогнозы на Betzona сам. Бот таблиц присылает ему заготовки (`betzonaSend_`).
- **Формат прогноза:**
  - ставка словами + кэф;
  - описание обычным текстом: история матча → доводы → риски → вывод «Беру …»;
  - без эмодзи и ссылок;
  - без слов «таблица», «модель», «расчёт», «вероятность», «по данным», «статистическ»: это запрещённые слова `POST_BANNED_` бота.
- Владелец любит развёрнутые описания (~2000–2500 знаков) с конкретными цифрами:
  - форма, дом/выезд, личные встречи за два сезона;
  - процент отражённых бросков, большинство/меньшинство, штрафные минуты;
  - отдых между матчами.
  
  Источники: листы «результаты матчей», «Результаты 2025-26», «Статистика_КХЛ», «Ключевые_игроки».
- Факты из одного источника (травмы из Telegram-каналов) не использовать.
