## 3. Как работали (повторять)
- Правка: ветка `claude/team-dev-site-…` от `origin/main` → PR в `main`. Аккаунту Б владелец разрешил вливать самому
  после проверок; **внешний вид — только после «было/стало» и «да» владельца**. Влил → `site.yml` вручную
  (`run_workflow`, ref main, inputs `{"plans":"no"}`) — сайт обновится через ~10 мин, не ждать 10:23.
- Локальная проверка без сети: живой сайт клонируется (`git clone --depth 1 https://github.com/sevasonyshahmatov-collab/sevasonyshahmatov-collab.github.io <папка>`),
  пересборка кодом ветки `SITE_URL=https://sevasonyshahmatov-collab.github.io/ python3 team/site/build.py <папка> --no-settle`,
  затем `node team/site/check.js <папка> <снимки>` → `CHECK OK`. Предупреждение про `app/bg/photos.json` — норма.
- CDN (jsdelivr/cdnjs) из облака закрыт: для проверки Lenis/GSAP — `npm pack lenis@1.1.20 gsap@3.12.5` и подмена
  запросов в Playwright (`page.route`) на локальные файлы.
- Видео было/стало: Playwright `recordVideo` (1440×900 и 390×780), сценарий прокрутки/нажатий, склейка
  `ffmpeg … hstack` с подписями «БЫЛО/СТАЛО» (шрифт DejaVuSans-Bold). Не нажимать ссылки `target=_blank` — откроется
  вторая вкладка и попадёт в склейку не тот файл.
- Отправка владельцу — скилл `jarvis-send` (`team/out/<день>/<имя>.json` в ветке команды, `itogi.yml`).
  **jpg/mp4 в `team/out/` игнорируются `.gitignore` — добавлять `git add -f`**.
- Шаги — строкой в «События» `team/NOW.md` (аккаунт Б).
