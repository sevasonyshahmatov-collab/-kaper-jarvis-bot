# Конвейер шортсов для YouTube — задание для нового чата (17.10.2026)

Владелец: «соберём конвейер, чтобы сам собирал видео и не тратил много лимитов». Цель — ежедневные шортсы на матчи
КХЛ (потом НХЛ) без участия Claude: всё считается и рисуется в GitHub Actions, владельцу приходит готовое.
Правила работы с владельцем: сначала план 3–4 строки → работа после «да»; 2–3 варианта, не больше; сообщения короткие,
на русском, без жаргона. Ветка: `claude/project-migration-old-account-6e31vz`. Не просить токены/ключи в чат.

## Что должен делать конвейер (один запуск в день, утром, после расчёта прогнозов)
1. **Матчи дня и данные**: `team/picks/khl_data.py` (официальное приложение КХЛ: сыгранные матчи, матчи дня, линия).
   Форма клубов для роликов (последние 3 игры, очки, матчи, место в конференции, разница) — готовый расчёт
   `team/out/2026-10-17/khl_stats.py` (вынести в `team/reels_daily/`).
2. **Прогноз на каждый матч — правило владельца (17.10)**: из вариантов «Что заходит» (`team/picks/calc.py`, строки
   BRIEF / PICKJSON `top` в логе расчёта — вероятность `p` и кэф `odds`) брать **наиболее вероятные события с кэфом
   1,6–2,3**. Равный матч (линия П1 и П2 близки) — ближе к 1,6–1,7; аутсайдер против сильного — 1,8–2,0.
   Пример 17.10: Сибирь — Барыс (2.60/3.70/2.40, равный) → ТБ 4,5 за 1,61; Сочи — Локомотив (6.80/4.70/1.41) → фора
   Локомотива −1,5 за 1,75. Если у владельца есть свой опубликованный прогноз на матч — спросить, какой брать
   (вопрос открыт).
3. **Ролик**: утверждённые шаблоны — `team/reels_selected/README.md` (16 шт.). Чередовать по матчам. Сборка как в
   `team/out/2026-10-17/khl_reels_make.py` (данные дня + `team/out/2026-10-13/reels_cfg/<формат>.json`).
   Прогноз на тотал: финал показывает обе команды (`form.pick_team`; сделано в `broadcast.py`, остальные шаблоны —
   добавить так же).
4. **Тексты для YouTube к каждому ролику**: название (команды + «прогноз на матч» + дата), описание (матч, время МСК,
   прогноз, «Все прогнозы раньше всех — в Telegram: t.me/jarvibet»), 3–5 хэштегов (#хоккей #КХЛ #прогноз …).
   Без «мнение автора», без букмекеров/промокодов/гарантий. Канал: `docs/channel/youtube/ОПИСАНИЕ_RU.md`.
5. **Доставка**: владельцу в Telegram (задание `team/daily/jobs/…`, тип `documents`/`video`, через `render/team_job.py`)
   — ролик + текст; загружает в YouTube сам (API-загрузка пока не оформлялась).
6. **Хранение**: каждый ролик — сжатая копия `tools/video_archive.py` → `videos/архив/` (коммит в ветку; в Actions нет
   прав на запись — либо дать workflow `contents: write` для этого шага, либо артефакт «videos» 90 дней + архив вручную).
7. **Расписание**: запуск из бота/таблицы (repository_dispatch) или `create_trigger` раз в день. Объём: неделя 1 —
   4–6 роликов в день, потом больше (`team/YOUTUBE.md`).
