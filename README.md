Зашифрованные треки владельца для роликов (AES-256). Ключ — только секрет репозитория TRACKS_KEY, в коде и логах его нет.
Расшифровывает render/reels/owner_tracks.py в GitHub Actions. В ветку команды не вливать.
Треки: quantum, north, kizaru, depto, slx, jefe, kilo, rotten, vace (имена как в render/reels/run.py TRACKS).
