# jarvis-ideas — идеи для канала, сайта, таблицы

Вход: тема владельца (может быть пустой — тогда по всем направлениям). Выход: список идей, ничего не делать самому.

## 1. Что уже есть (не больше 8 файлов)
- Было и не повторять: `team/LOG.md` (последние ~60 строк), `team/BACKLOG.md`, `team/POSTS.md`, `team/PLAN.md`.
- Что сработало: последний снимок Instagram (`team/out/*/ig_snapshot*.json`, поле `ab`, просмотры, досмотры),
  статистика прогнозов сайта (`stats/months.json` в репозитории сайта), `team/PICKS.md` (что заходит).
- Правила: `team/RULES.md`, роль стратега `team/roles/strategist.md`, голос `.claude/instagram/voice.md`.
- Ближайшие матчи и события (дерби, серии, рекорды, плей-офф, перерывы лиг) — из данных лиг, если тема про контент.

## 2. Направления (берёшь те, что в теме; без темы — по 1–3 идеи на каждое)
- **Telegram-канал:** рубрики между прогнозами (опрос дня, цифра дня, разбор после матча, «как я выбрал»), вовлечение
  (реакции, комментарии, викторины), закреп, ритм дня.
- **Instagram / YouTube:** карусели, Reels, хайлайты, истории — что удержит в первые 3 секунды.
- **Сайт:** что принесёт людей из поиска и вернёт их (страницы матчей, сравнение команд, «трендов» и т. п.).
- **Аналитическая таблица:** новые листы, расчёты, удобство; что из неё показать подписчикам.
- **Бот и автоматика:** что сэкономит время владельца.
- **Рост:** взаимный пиар, площадки, сезонные поводы — то, что может только владелец.

## 3. Как писать идею
Каждая — живая, конкретная, на наших данных (не «делать больше контента»). Формат:

```
### <№>. <название в 3–6 слов>  ·  <направление>
Что: <1–2 фразы — что именно увидит подписчик / владелец>
Зачем: <какую цель решает — рост, удержание, доверие, время владельца>
Пример: <как выглядит на реальном матче / команде / цифре из данных>
Польза: <1–5>  ·  Усилия: <1–5>  ·  Делает: <команда сама / нужен владелец / нужны деньги>
Чем делать: <скилл или скрипт: jarvis-*, ig-*, impeccable, render/, team/site/…>
```

## 4. Отбор
- 8–12 идей, отсортировать по «польза − усилия»; первые три — «начать с этого».
- Убрать: повторы из LOG/BACKLOG, всё против правил канала (прогнозы и кэфы в канал, БК, промокоды, гарантии,
  выдуманные цифры), то, что нельзя проверить.
- Хотя бы одна смелая идея, которой у конкурентов нет (на наших моделях, таблице, симуляциях).
- В конце — одна строка: «Выбери номера — по ним jarvis-brief напишет ТЗ».
