# jarvis-postmatch

1. Возьми фактическую ставку: последняя «правка владельца в боте» по номеру в `team/INBOX.md`, иначе — пост прогноза
   в `team/out/<день>/picks_<khl|nhl>.json`. Если владелец сам назвал ставку — бери его слова.
2. Запусти `itogi.yml` (как в скилле `jarvis-send`, шаг 3) с payload:
   ```json
   {"kind":"team","job":"team/out/<день начала>/postmatch_auto.json","day":"<день начала>",
    "pm":{"pid":"2510-4","league":"KHL","home":"Спартак","away":"Шанхайские Драконы",
          "start":"2026-10-25 17:00","pick":"индивидуальный тотал Спартака больше 2,5","kef":"1,85"}}
   ```
   День — дата начала матча по МСК (НХЛ ночью — уже следующее число). `pid` — номер прогноза: кнопка «Опубликовать»
   выложит итог ответом на пост прогноза в канале. Задание создаётся из заготовки само, коммитить ничего не нужно.
3. Матч должен быть доигран, иначе поста не будет. В логе — строка `→ owner · animation · ✅/❌ <b>Хозяева — Гости счёт</b>`.
   Шаг «Нарисовать и отправить» обычно ~1,5 мин; висит дольше 5 мин — отмени и перезапусти, не жди 20.
