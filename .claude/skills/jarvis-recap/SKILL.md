# jarvis-recap

1. Список ставок: от владельца или из `team/INBOX.md` (правки в боте). Строки — в виде, который понимает
   `team/daily/ask.py` `parse_free`: `Прогноз: Хозяева — Гости: ставка, кэф 1,72` (кэф можно не писать).
   Перед запуском проверь разбор локально: `parse_free(lines, games)` на подставных матчах (см. `ask.py`).
2. Задание с ожиданием доигрывания (до 35 мин) — свой файл `team/out/<D>/recap_owner.json`:
   `{"day":"<D>","make":["team/daily/morning.py <D> --ask --recap-only --job-file team/out/<D>/recap_owner.json"],"messages":[]}`
   (шаблон `recap_ask` запускает с `--no-wait`: недоигранный матч выпадет). Закоммить и запушь.
3. Запуск `itogi.yml` с payload:
   `{"kind":"team","job":"team/out/<D>/recap_owner.json","day":"<D>","pids":[],"at":"<D> ЧЧ:ММ","free":["Прогноз: …", …]}`.
   `<D>` — утро после игрового дня; матчи берутся с 08:00 вчера до 08:00 `<D>` МСК.
4. В логе — `DAILY_SCORES` по каждой ставке и `DAILY {… "picks": N …}`: N должно совпасть со списком. Матч «не доигран —
   в итоги не вошёл» — перезапусти после финала. Лишние варианты итогов владелец убирает кнопкой «Не надо».
5. Нужен только баннер без расчёта — `team/daily/banner.py` `render(rows, out_dir, date_title)`, пример
   `team/out/2026-10-24/recap_fix.py`.
