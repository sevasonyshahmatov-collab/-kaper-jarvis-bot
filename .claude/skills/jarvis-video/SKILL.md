# jarvis-video — новые ролики и шаблоны

Вход: бриф (лучше — от `jarvis-video-analyst`). Нет брифа на новый формат — сначала вызвать аналитика.

## 1. Экономия лимитов (обязательно)
- Не писать с нуля: найди в `render/reels/` 1–2 похожих шаблона и собери новый из их частей (`core.py` — текст, плашки,
  эмблемы, `odds_row`; `beats.py` — ритм и дроп трека; `card.py`, `board.py`, `cinema.py` и т. д.). Читать только нужные
  функции (Grep), не файлы целиком.
- Проверка кадрами, не роликом: `PYTHONPATH=render python team/reels_daily/make.py render <лига> <день> --part 1
  --frames 2,9,15,20` (план — `make.py plan …`; данные лиг из облака закрыты — тогда фикстура/прошлый план).
  Смотреть 2–4 кадра (Read картинки), правки пачкой, повторный снимок — один раз.
- Полный ролик со звуком — только в Actions: «Шортсы — конвейер» (`reels-daily.yml`), из ветки — строка в
  `team/reels_daily/RUN` («лига день [сколько]»). Ролик — артефакт запуска; владельцу — через `jarvis-send`
  (`documents`, одно видео — одно сообщение, ≤ 50 МБ).

## 2. Как делать шаблон
1. Новый файл `render/reels/<имя>.py` по образцу похожего: та же функция входа, те же поля данных (команды, форма
   3 последних игр, очки, прогноз, кэф, факт), 1080×1920, 4K-проверка `render/quality.py`.
2. Крючок первых 1,5 с — как в брифе (вариант А/Б из `make.ab` не ломать: он идёт через один ролик).
3. Стиль канала: золото на тёмном, эмблемы без белой обводки, крупный текст, «показать, а не рассказать»; для
   графики — правила `impeccable` (типографика, отступы), без мелкого текста.
4. Правила роликов (`team/RULES.md` «Ролики»): в прогнозе — ставка, без «шансов» и процентов модели; без БК,
   промокодов, гарантий; трек — из треков владельца (зашифрованы, ключ TRACKS_KEY только в Actions).
5. В очередь шаблонов — только после «да» владельца по превью (список в `team/reels_daily/README.md`, `make.py`).

## 3. Разовые ролики (анонс, итоги недели, реклама таблицы)
Тот же набор `render/reels/`, задание `team/out/<день>/<имя>.py` + `jarvis-send` (`make` рисует ролик в Actions).
Данные — только настоящие (таблица, сайт `stats/months.json`, `team/PICKS.md`).

## 4. Отчёт
Что сделано, какой шаблон взят за основу, 2–4 кадра превью (пути), что владельцу решить (в очередь / поправить),
как будем сравнивать (передать `jarvis-video-analyst`: группа, поле снимка, срок).
