# jarvis-picks

Аргумент — лига (`khl` или `nhl`), при необходимости день `ГГГГ-ММ-ДД` (по умолчанию сегодня по Москве).

0. Сначала проверь, не сделано ли уже (задачи прогнозов могут стоять на двух аккаунтах, `team/NOW.md`): `git pull`,
   есть коммит с постами владельцу по этой лиге за этот день — ничего не делай, верни «уже отправлено (коммит …)».
   Есть только задание данных или часть файлов в `team/out/<день>/` — продолжи с них, отправленное не дублируй.
1. Выполни `team/picks/README.md` шаги 0–8 для этой лиги и дня — порядок, правила текстов (`team/POSTS.md`) и экономия
   токенов (раздел 10 README) обязательны. Качество анализа и текстов не снижать: это главный продукт канала.
   **Пост — на каждый матч дня (владелец 30.10):** не прошёл порог «ВЫБОР» — не пропускать, а самая вероятная ставка
   с кэфом от 1,6 и строка «Уверенность модели ниже 60 % — ставка рискованнее обычной.» (README, «Посты на ВСЕ матчи дня»;
   образец — `team/out/2026-10-30/mk_nhl.py`).
2. Вернуть в основной чат только итог (README, шаг 9): лига, номера отправленных постов, номер запуска Actions,
   сколько постов с пометкой «ниже 60 %». Логи, факты и черновики в ответ не включать — они уже в файлах `team/out/<день>/`.
